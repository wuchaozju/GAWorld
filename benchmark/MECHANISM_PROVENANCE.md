# 机制来源表

日期：2026-09-25
用途：**每一条结论在引用某个指标之前，先在这里查这个指标依赖的机制属于哪一类。**

这份表是 2026-09-19 那轮提案里 P7 的落地。当时的理由是：GAWorld 已经吃过两次
「把自己写进去的东西当发现」的亏（Track A 的循环论证、group agent 的单种子 L2）。
建立 agent→环境反馈之后这个风险被放大，因为涌现结果**看起来更像发现**。

---

## 分级定义

| 级别 | 含义 | 能支撑什么 |
|---|---|---|
| **(a)** | 从真实数据校准 | 可以单独立论 |
| **(b)** | 从文献搬来的标准机制，参数有公开区间 | 可以单独立论；须注明出处与参数取值 |
| **(c)** | 我们自己定的合理猜测，或按某个目标标定出来的旋钮 | **不得单独立论**。只能用「跨取值的方向一致性」立论，并且**被用来标定它的那个量，不再是它的证据** |

第三条最后半句是整张表的重点。一旦用通勤时长标定了 `distance_decay`，通勤时长就不
再是 `distance_decay` 的证据；还想用通勤时长立论，就得换一个没参与标定的判据。

## 人口与经济

| 机制 | 级别 | 出处 / 理由 | 代码 |
|---|---|---|---|
| 失业率 = 失业 / 劳动力 | **(b)** | ILO 口径，退休与在读学生不进分母 | `economy/finance.py` |
| 人口 IPF 拟合（年龄 × 就业等边缘分布） | **(a)** | 对规格里的真实统计目标拟合 | `population/synth.py` |
| 收入以 profile 声称值为锚 | **(a)** | 采纳人口合成器按 median/gini 目标采样的结果，不再由职业名重摇 | `economy/finance.py` |
| 需求拉动通胀 π = π\* + κ·(C/C₀ − 1)，C 为人均实际消费 30 天均值、C₀ 为开头 30 天基线 | 形式 **(b)**，参数 **(c)** | 需求拉动 / 产出缺口是标准形式；κ=0.5、π\*=2.5%、基线期、工资跟涨 0.5 都是猜的。默认关（`economy.macro.inflation`）。小人口下需求缺口噪声大，且会把工资涨落原样传成通胀、人口少时一户的开销变化就能拉动通胀（大病自付费已不计入需求：此前 3 人测试里一次 2.1 万元急诊让通胀顶到上限 30 天）——通胀**水平**不得单独立论 | `economy/finance.py` |
| 加薪 / 裁员概率（`raise_base_prob` + `raise_chance`、`layoff_base_prob` + `layoff_risk`），**每人每月** | **(c)** | 数值是猜的。按月读，扩张期每月 0.3% 被裁、谷底 2.6%；美国 JOLTS 裁员与解雇率常态约 1.0%/月（BLS 2024-05）——扩张期偏低。**2026-10-03 起按月解释**（可比性版本 7）：此前按天抽，默认周期一年后中位工资落在最低时薪（2000 人测：p10/中位 0.10/0.10 → 0.51/1.00）。随机裁员 30–90 天后回到原工资的 85–100%（可比性版本 8，此前永久；p10 → 1.00），85–100% 照搬人生事件复职的「疤」，同为 (c)。医疗急症仍按天（0.0005/天 ≈ 每年 17%） | `economy/finance.py:_check_daily_shocks`；`docs/proposals/2026-10-03-monthly-shock-probabilities.md` |
| 带薪年假：每年 5 个工作日，每天发 `gross_monthly_salary ÷ work_days_per_month` | 额度 **(a)**，其余 **(c)** | 5 天取《职工带薪年休假条例》第三条工龄 1–10 年的最低档（模型不记工龄）；日薪口径是通常做法；不区分零工（约一成人口也拿年假）。只影响默认关的离城功能 | `economy/finance.py:credit_paid_leave`、`travel.paid_leave_days_per_year` |
| `profile_income_jitter` | **(c)** | 只为避免整镇收入都是整数；设 0 即严格照发 | 0.08 |
| 职业 → 行业的子串匹配 | **(c)** | **已知失效**：「跨境电商运营」被判成 service。合成种群现在直接带 `industry` 列，这条只对老语料生效 | `economy/finance.py` |
| 非就业人群的低收入带（8–22 元/时） | **(c)** | 刻意给的低收入而非零收入；此处**没有养老金发放机制**，改成 0 会让开局即退休的人立刻赤贫。学生的「复习 / 训练」也算有收入的活动，且照扣个税和社保。**因此 Track A 的 `wealth_gini` 只在劳动力人口（employed + unemployed）上计算**（2026-10-03 决定；economy 本身未改），scorecard 里写明计算范围；没有 `employment_status` 列的旧输出退回全体并注明口径偏宽 | `economy/finance.py`、`benchmark/gaworld_bench.py` |

## 居民状态与消费预算（研究指标、Track A / C 依赖的机制）

2026-10-03 补齐。研究闭环能测的指标和 Track C 的已知符号检验都读这些状态，Track A 的恩格尔系数与储蓄率读消费预算。

| 机制 | 级别 | 出处 / 理由 | 代码 |
|---|---|---|---|
| **事件 → 九维状态的影响** | **(c)** | 每个事件 / 政策，对每位居民发**一次模型调用**，让它给出九维状态的增量（截断到 ±0.2）。效应的**方向就是模型对这件事的判断**：「补贴提高经济安全感」「裁员降低经济安全感」在很大程度上是在复述这次调用的答案。这是平行世界、研究闭环与 Track C 里事件效应的主通道 | `generative_city_sim.py:infer_event_effect` |
| 九维状态的均值回归动态 | **(c)** | 每步向一组目标值回归（目标是 0.42–0.58 之间的基数加上各状态之间的线性项），回归速率 0.12–0.18、噪声 ±0.008–0.012——全是定的。它会把事件冲击逐步拉回，所以效应的**持续时间**也是这组系数决定的 | `generative_city_sim.py:update_state` |
| `econ_security` 的账本通道 | **(c)** | 每天 `0.85 × 昨日 + 0.15 × (0.30 + 0.70 × 资产得分)`，资产得分 = min(有效资产 / 三个月开销, 3) / 3；权重是定的 | `economy/finance.py:_update_econ_security` |
| 情绪的社交传染、动态行为心情增量、记忆唤起效应 | **(c)** | 传染速率 0.1、唤起效应 0.015 等都是定的 | `sim/_cognition.py`、`sim/_memory_recall.py` |
| 人生事件、家庭事件的固定状态增量 | **(c)** | 每类事件一组写死的增量（如突然生病：情绪 −0.08、压力 +0.14） | `events/life.py`、`family/events.py` |
| 生理 / 需求状态（精力、饥饿、疲劳负债……） | **(c)** | 手写目标值与回归速率 | `generative_city_sim.py:update_state` |
| 干预指标（立场、毒性、误信息、跨观点曝光、干预奖励） | **(c)** | 对信息流与居民所写文字做关键词匹配；关键词表、平滑系数 0.8、奖励权重都是定的。文字由模型生成 | `policy/intervention.py` |
| 恩格尔曲线（收入五档 → 食品占比、储蓄率） | **(c)** | 五档系数（0.48 / 0.38 / 0.30 / 0.22 / 0.15，储蓄率 0.05–0.40）没有注明出处。**快照里的 `engel_coefficient`、`savings_rate` 就是按收入查这张表的结果**，不是从实际消费算的 | `economy/finance.py:_engel_params` |
| 开局存款 = 月净收入 × U(1, 6) 个月 | **(c)** | 区间是定的；短期运行里财富分布主要由它和收入分布决定 | `economy/finance.py`（`initial_savings_months_*`） |

## 指标的最弱依赖（规矩 3 的落地）

研究闭环与 Bench 引用一个指标时，带上下表里它的级别。代码里的出处：研究指标在 `gaworld/research/measures.py`（每个指标的 `grade` / `basis`，问卷指标在 `research/survey.py`），Bench 在 `gaworld_bench.py` 的 `METRIC_PROVENANCE` / `STATE_PROVENANCE`；两边的九维状态级别由测试锁成一致。

| 指标 | 最弱依赖 | 级别 | 备注 |
|---|---|---|---|
| 九维状态（研究指标；Track C 的 `econ_security` / `stress` / `mobility_intent`） | 事件 → 状态的模型调用、均值回归系数 | **(c)** | Track C 检的是模型对事件的判断能否穿过状态动态，不是现实因果的独立检验 |
| 干预指标 | 关键词表与权重 | **(c)** | `stance_score` 取值 −1–1 |
| 生理 / 需求状态 | 手写规则 | **(c)** | |
| 问卷指标 `survey.Q<n>` | 模型扮演居民的自述 | **(c)** | |
| Track A `engel_coefficient`、`savings_rate` | 恩格尔曲线 | **(c)，回显** | 拟合量的是这张表；改从实际分类消费计算前，不是模型证据 |
| Track A `wealth_gini` | 开局存款区间 | **(c)** | 收入锚点本身是 (a) |
| Track A `commute_minutes`、`transit_share` | `distance_decay`、`agents_represent` | **(c)** | 本来就口径不符、不计分 |
| 群体模式下非实体化居民的状态（`simulation_mode: "group"`） | 每个群体一次模型调用给出的群体变化，作为共同平移施加 | **(c)** | 与快进简报同级；每日审计残差（`group.day`）量的是它离个体层多远，不是离现实多远 |
| 经典实验库（六个范式的配对效应，`gaworld/experiments/classics/`） | 模型扮演居民对一段题面的一次回答 | **(c)** | 只读方向；人类数字只作对照 |
| Track B 对局层（公投从众、灾害恐慌 / 互助、辟谣后的残留相信） | 模型扮演居民对一段提示词的一步回应 | **(c)** | 只读定性结论；每条的提示词线索写在报告里（`gaworld_bench.py` 的 `B_FACTS`） |
| Track D 人类判别（「谁是真人」里居民被判成真人的比例 ÷ 真人的） | 群聊格式：居民的短句口语规则、话题、`D_PASS = 0.7` 都是我们定的 | **(c)** | 票是真人投的，不是模型给模型打分；但换一种格式结论可能就变，只读「在这个格式里分不分得开」；评委是同局玩家、票不独立 |

(c) 级指标的结论**只读方向，效应大小不作数**：研究的结果与报告在每个效应旁写明，模型解读给 (c) 级指标写了具体大小会被标出；
Bench 的 scorecard 与报告列出每个指标的最弱依赖和「回显」标记。判定规则与分数不变。

## 对 Track A 两个通勤锚点的当前判定

| 锚点 | 状态 | 理由 |
|---|---|---|
| 单程通勤 34.5 min | **口径不符，不计分** | 全市口径 vs 片区仿真 |
| 公交机动化分担率 47.6% | **口径不符，不计分** | 同上 |
| 绿色出行 >70% | **口径不符，不计分** | 同上 |
| 单程通勤距离 8.1 km | **口径不符，不计分** | 片区最多做到 5.94 km，19 km 的图上没有那条尾巴 |
| 5 公里以内通勤比重 52% | **口径不符**（但片区能复现 52.3%） | 复现属巧合级证据，不单独立论 |

**这不是「还没调到」，是尺子和被量的东西不是一回事。** 仿真的是杭州滨江一带约
19×15 km 的片区，锚点描述的是全杭州。一个半数通勤在 5 公里以内的片区，本来就该比全市
更多步行骑行、更少小汽车。

已按 2026-09-25 的决定（方案 B）落实：`gaworld_bench.py` 的每条锚点带 `scope` 字段，
`city_wide` 的只报告不打分（`context_metrics`），并有回归测试锁住。
要恢复这些锚点的判据资格，只有两条路：换成全市口径的地图，或找到片区口径的参照。

## 维护规矩

1. 每加一条 agent→环境的机制，同时加一行。
2. (c) 类旋钮的默认值变更，要在提案里写明「按什么标定的」。
3. Bench 的 scorecard 引用某个指标时，附上它最弱的那一级依赖。（2026-10-03 起由代码做，见「指标的最弱依赖」。）
4. 给研究闭环加一个可测量指标，同时给出它的 `grade` 与 `basis`；一个指标升级到 (b) / (a)，要在这里写明依据。
