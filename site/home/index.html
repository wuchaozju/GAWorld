研究流程

让实验过程可以回看

GAWorld 将居民生成、仿真运行、干预和结果分析连接起来。每一步都可以回到具体配置与运行记录。

研究工作台 ↗

  1. 构建研究对象

    设置居民、城市环境与模型。

  2. 设置实验条件

    明确对照、干预与观察指标。

  3. 运行与观察

    检查行动轨迹、访谈与互动记录。

  4. 比较与分析

    比较配对结果，查看不确定性与运行差异。

任务能否完成，以及行为是否接近匹配的人类参照，是两类不同的问题。查看各条评测轨道的协议、结果与适用范围。

快速开始

一条命令安装 GAWorld

需要 Python 3.11+ 与 Git。安装后打开控制台，在配置页设置自己的模型服务。

Terminal
python -m pip install "git+https://github.com/wuchaozju/GAWorld.git@main"
gaworld dashboard

在浏览器打开 127.0.0.1:8766
