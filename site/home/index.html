I · THE PLATFORM

GAWorld 模拟什么？

个体的决定与生活经历、家庭责任和社会环境有关。GAWorld 将这些条件纳入居民和环境配置。

01—04

从个体行为，
到社会情境。

人物档案提供文化背景与生活经历，记忆、关系和家庭责任为决策提供信息。地理、经济和事件设置构成居民行动的环境。

纳入文化背景是一种建模选择，其真实性仍需要与匹配的人类参照比较。

01

居民与记忆

编写居民档案，配置大五人格、情景记忆与长期目标，查看个体行为。

03

04

II · RESEARCH

将研究问题
写成可比较的实验。

在平行世界中比较政策或事件，查看配对居民结果、bootstrap 不确定性与跨种子结果，同时检查对应的仿真记录。

研究设计示例 · 不展示实测分数

通勤条件改变后，居民如何重新安排一天？

固定居民与随机种子，比较基线世界和交通干预世界；观察日程、位置和家庭责任如何变化。

III · EVALUATION

评估任务表现，
也评估人类效度。

GAWorld Bench 分别报告功能效度与人类效度，提供实验协议、评分分母和结论边界。

查看 GAWorld Bench ↗
F

功能效度

任务表现、记忆、推理、工具与历史机制消融。

H

人类效度

问卷回答、行为博弈分布与心理任务中的条件选择。

当前 A35/A37 原生问答每项使用一个 agent，不能直接证明完整多 agent 协作或长期城市仿真效度。历史 FOS 实验保留独立协议。

开始实验。

# 02 / open the console

浏览器访问 http://127.0.0.1:8766。启动 LLM 仿真前，请在配置页填写自己的模型接口与 API Key。安装和浏览控制台不需要共享密钥。
