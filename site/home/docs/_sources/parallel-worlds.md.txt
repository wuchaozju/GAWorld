# 平行世界与对照实验

平行世界从同一批居民出发，为不同条件设置事件或配置。你可以比较一个冲击发生前后的变化，也可以扫描一个参数的多组取值，观察差异何时出现、集中在哪些居民身上。

## 建立共同基线

打开 **研究工作台 → 平行世界 · 反事实推断**。先设置所有世界共用的居民、模型、仿真天数、随机种子与快速模式，再定义各个世界的事件和配置补丁。

一次实验支持 2–8 个世界。并行世界数控制同时执行的进程数，与实验中的世界总数分别设置。

## 完成一次对照运行

1. 选择 **裁员冲击**、**交通限行强度**、**安慰剂对照** 或 **严谨对照** 模板。
2. 检查基准世界、处理世界以及各自的事件时间和描述。
3. 首次运行将天数设为 2 天，开启快速模式，确认流程与输出。
4. 点击 **运行平行世界**，查看各世界的排队、运行与完成状态。
5. 完成后选择指标，查看轨迹、相对基准差异与报告。

正式比较时，按研究问题确定时长、重复种子和安慰剂条件。[研究工作台](research.md) 可以把这些设置连同假设整理成预注册协议。

## 定义各组的差异

| 设置 | 用途 |
| --- | --- |
| 事件 | 指定发生时间、名称与居民感知到的描述 |
| 配置补丁 | 改变该世界的一项机制或参数 |
| 角色 | 指定处理条件或安慰剂条件 |
| 剂量 | 表示不同处理强度，用于剂量反应分析 |

配置补丁按层合并，例如只改变个税起征点：

```json
{
  "label": "低起征点世界",
  "events": [],
  "config": {
    "economy": {"tax": {"monthly_exemption": 3000}}
  }
}
```

居民、种子、天数和输出目录由实验统一管理。配置补丁用于各组需要改变的机制参数。

## 扫描一个参数

在 **参数扫描** 中选择数值配置项，输入多组取值，生成“基准世界 + 每个取值一个世界”。检查生成的世界卡片与剂量，再启动实验。已有基准事件会复制到各组，便于比较同一情境下的参数影响。

生成扫描世界会替换当前的世界列表；先保存需要保留的设计。

## 阅读结果

| 结果 | 阅读方式 |
| --- | --- |
| 分叉图 | 查看各世界何时稳定偏离基准 |
| 指标走向 | 比较同一指标的时间序列与相对基准差值 |
| 谁被改变了 | 回查同一居民在不同条件下的结果 |
| 反事实推断 | 查看配对效应、区间、检验与判定 |
| 异质性 | 按居民属性比较条件效应 |
| 跨种子重复 | 检查相同设计在不同随机种子下的结果 |
| 剂量反应 | 查看结果随处理强度或参数取值的变化 |

这些估计描述所设仿真条件下的差异。解释结果时，结合事件前差异、安慰剂噪声、跨种子一致性与具体居民轨迹。

## 保存与复查

实验保存在 `output/parallel_worlds/<实验目录>/`，包括 `experiment.json`、`report.json`、`divergence_summary.md` 和各世界输出。保留实验定义、初始居民、模型设置与代码版本，便于重复运行。

命令行读取已保存的实验定义：

```bash
gaworld parallel-worlds --spec worlds.json
```

完整参数与报告字段见仓库的 [平行世界说明](https://github.com/wuchaozju/GAWorld/blob/main/docs/PARALLEL_WORLDS_TUTORIAL.md)。
