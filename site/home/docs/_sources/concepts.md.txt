# 工作区、城市与世界

GAWorld 通过居民、城市、世界和运行组织一次社会仿真。

## 数据与运行的组织

| 概念 | 含义 |
| --- | --- |
| 工作区（Workspace） | 保存代码、输入数据、配置与产物的项目目录 |
| 居民（Agent） | 具有身份、状态、记忆、人格与社会关系的行动主体 |
| 城市（City） | 地图、环境配置与初始居民组成的数据包 |
| 世界（World） | 一组居民、运行配置与输出的工作单元 |
| 运行（Run） | 在指定居民、模型和时间设置下推进的一次仿真 |
| 插件（Plugin） | 通过内核服务和生命周期钩子接入的子系统 |

```text
研究问题 → 城市与居民 → 世界配置 → 仿真运行 → 记录与分析
                              ↑                 ↓
                         事件与政策 ←── 对照实验
```

## 居民的行动过程

日常仿真按认知管线推进：

```text
准备 → 感知 → 中断处理 → 计划 → 日程调整 → 移动
     → 选择行动 → 反思 → 状态更新 → 广播 → 记忆 → 记录
```

身份、状态和历史经历参与决策；空间与环境影响可执行行动；行动结果继续进入状态和记忆。

## 城市、团队世界与实验世界

```{figure} _static/diagrams/data-relationships.svg
:alt: 城市居民输入复制到团队世界，世界运行保存结果，平行实验从共同输入派生独立输出
:figclass: guide-diagram
:target: _static/diagrams/data-relationships.svg

输入、配置和产物的关系。箭头标明复制、读取或写入，便于判断一次修改影响哪里。
```

| 对象 | 保存什么 | 修改后的影响 |
| --- | --- | --- |
| 城市包 `data/cities/<slug>/` | 地图、环境、居民初始状态与档案 | 后续选择此城市的运行读取对应配置 |
| 团队世界 `output/worlds/<id>/` | 城市选择、居民输入副本、世界配置与输出 | 世界内编辑居民更新自己的副本；城市后来编辑居民不会同步到已有副本 |
| 平行实验中的条件世界 | 共同输入、各组事件或参数，以及各组独立输出目录 | 用于一次实验内的条件比较，位置在 `output/parallel_worlds/` |
| 运行 | 一次启动产生的日志、状态和轨迹 | 普通运行是否接续记忆取决于 `stateful`；轨迹有运行归档 |

团队世界复制居民输入，并通过城市配置读取地图与环境。它的隔离重点是居民副本、配置覆盖与运行结果。平行实验为每个条件重定向输出目录并从初始输入运行；实验条件世界由实验运行器管理。

## 再次运行与保存结果

`stateful` 开启时，仿真加载居民已有的记忆、关系及持续状态，并接续其仿真日期。普通运行会更新当前输出文件；轨迹另外保存在 `visualization/runs/<run_id>/`。

**重置并运行**先清理当前输出，再使用居民初始输入。需要完整保留状态 CSV、日志和记忆时，先复制相关运行目录，或将条件组织为平行实验。轨迹归档保存的是回放数据。

## 访谈访问哪一份居民

群体采访从选定城市包构造受访名单，适合比较城市人口与群体。研究工作台的组合研究（`composite`）在各条件运行后，带着该世界的运行记忆进行问卷。比较“干预后的回答”时选择后者，操作见 [研究工作台](research.md)。

## 时间尺度

普通运行保留日内行动。长时段快进按天、月或年生成阶段简报，用于研究较长时间的变化。时间尺度会改变输出细节，实验各组应保持一致。

## 事件与干预

环境事件进入居民感知，控制器处理动作校验与运行时干预。平行世界把不同事件施加到共同基线上，记录条件之间的配对差异。

## 配置与复现

保存居民初始数据、城市、模型、随机种子、时长、时间步长和干预设置。结果应与所用代码版本对应，便于复查和重复运行。
