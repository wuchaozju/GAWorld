模块与参数管理¶

GAWorld 通过模型后端调用语言模型。管理员登记服务商与模型，用户保存自己的 API Key，并为自己的世界选择默认模型和日程模型。

连接模型服务¶

  1. 使用自己的账号登录控制台。

  2. 打开 配置 → 模型，找到要使用的后端。

  3. 在 我的 API Key 中填写该服务商的密钥并保存。

  4. 点击测试连通性，确认一次短调用能够完成。

  5. 回到仿真页面，设置默认模型和日程模型，保存配置。

首次配置完成后，运行少量居民、较短时长的仿真，检查日志和模型输出。

配置字段¶

字段

填写内容

服务商 / 模型后端

控制台中已登记的模型配置

协议

服务商提供的接口格式，例如 OpenAI 兼容或 Anthropic 兼容协议

Base URL

服务商的完整 API 基础地址

模型 ID

服务商接受的模型名称

我的 API Key

当前账号在该服务商的 API 密钥

默认模型

当前世界中默认使用的模型后端

日程模型

当前世界中用于日程生成的模型后端

OpenAI 兼容协议描述的是接口格式；密钥由你选择的服务商提供。相同账号、协议与 Base URL 下的模型预设可以复用已保存的密钥。

添加模型后端¶

管理员在 配置 → 模型 → 新增后端 中填写服务商地址、协议和模型 ID。保存后，用户可以在列表中选择该后端，并填写个人密钥。

本地 Ollama 也可以作为模型后端。管理员需要使用部署环境可访问的 Ollama 地址，并确认对应模型已加载。

选择运行参数¶

模型的并发、超时、输出长度和思考模式都会影响一次仿真的调用过程。较长上下文或本地模型首次加载时，可以适当增加超时。

进行对照实验时，把模型 ID、服务商、思考模式和运行配置一起保存，便于比较与复现。

排查连接问题¶

现象

检查步骤

提示缺少 API Key

确认已登录正确账号，并为所选服务商保存密钥

返回 401 或 403

检查密钥是否有效、模型访问权限以及服务商 API 额度

返回模型不存在

核对模型 ID 与服务商当前提供的名称

请求超时

检查网络、后端运行状态和超时设置

短调用成功，完整运行失败

检查余额、并发限制、输出长度及仿真日志中的具体错误

模型预设及部署配置可查阅仓库中的 模型接入说明。

参数来源与覆盖¶

基础配置由 gaworld/settings/defaults.py 汇集各配置模块。dashboard_config.json 保存控制台覆盖项；环境配置与城市包提供环境、地图和居民路径；GAWORLD_CONFIG_OVERRIDES 提供最终的运行覆盖。

在 Python 中读取配置：

from gaworld.settings import build_config

config = build_config()
print(config.get("city"))

环境变量覆盖使用 JSON 对象：

export GAWORLD_CONFIG_OVERRIDES='{"skills":{"max_per_prompt":2}}'

模块装配¶

内置插件由 gaworld/plugins/ 装配。自定义插件可以通过 CONFIG["plugins"]、gaworld.plugins entry point 或注册表接入。插件使用唯一 ID，并以 requires 声明依赖。

运行设置¶

居民选择、仿真时长、模型、时间步长和随机种子共同定义运行条件。控制台中的当前世界也决定输出位置。保存实验时，把这些设置与城市和居民初始数据一起保存。

查看接口配置¶

GET /api/config 读取运行配置；接口结构与权限说明由 GET /api/openapi.json 提供。Python 配置入口见 配置模块。
