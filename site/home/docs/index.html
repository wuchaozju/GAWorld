快速开始与版本差异

安装与启动

当前安装要求 Python 3.11 或更高版本，并已安装 Git。通过 GitHub 地址安装后，使用 gaworld dashboard 打开本地控制台。

python -m pip install "git+https://github.com/wuchaozju/GAWorld.git@main"
gaworld dashboard

浏览器访问 http://127.0.0.1:8766。首次运行会准备默认工作区 ~/.local/share/gaworld/workspaces/default。希望选择工作目录时，使用以下命令。

gaworld init ./my-world
cd my-world
gaworld dashboard

初始化后的工作区保留自己的版本与数据。升级安装包后，可在新目录初始化新版本，再单独迁移个人数据。

README.md

配置模型

进入“配置 → 模型”，选择服务商，填写对应的个人 API Key 并测试连通性。在自己的世界中设置默认模型与日程模型，再做小规模试运行。管理员维护模型后端；普通用户管理自己的密钥和世界配置。

密钥与账号、协议及完整 Base URL 绑定，不应把不同服务商的密钥混用。连通性探测通过只说明该次短调用成功，完整仿真还受余额、权限、并发、超时和输出配置影响。具体预设以部署版本为准。

docs/MODEL_PROVIDERS.md

旧文档需要对照的地方

Python 版本：旧 TUTORIAL 提及 Python 3.10；当前包声明要求 Python 3.11+。

配置位置：旧指南中的根 config.py 修改方式属于历史写法。当前配置在 gaworld/settings/，模型接入以 MODEL_PROVIDERS 为准。
