GAWorld 文档¶

GAWorld 是生成式多智能体社会仿真平台。你可以创建城市与居民，让居民在环境中行动、工作和建立关系，再通过事件、政策与对照实验研究个体和群体的变化。

从一次仿真开始¶

安装 GAWorld，创建工作区并启动控制台：

python -m pip install "git+https://github.com/wuchaozju/GAWorld.git@main"
gaworld init ./my-world
cd my-world
gaworld dashboard

打开 http://127.0.0.1:8766，依次完成模型配置、城市与居民选择、运行和结果查看。第一次仿真 给出完整操作步骤。

城市、居民与世界¶

城市保存地图、环境和初始人口。居民具有身份、人格、状态、记忆与社会关系。世界保存一组居民副本、运行配置和输出；一次运行按选定时间尺度推进居民行动。

在同一套城市与居民基础上，你可以跟踪一次日常仿真，也可以建立多个实验条件，比较事件或配置改变后的轨迹。概念之间的关系见 工作区、城市与世界。
