第一次仿真¶

本节完成一次从配置到查看结果的仿真。

前置条件¶

完成 安装，进入工作区并启动控制台：

cd my-world
gaworld dashboard

确认当前世界¶

本地工作区可先使用默认世界。团队部署中，登录后在 管理世界 中选择城市、新建自己的世界，再切换到该世界进行配置与运行。

配置模型¶

  1. 打开 配置 → 模型，选择模型服务商。

  2. 填写 我的 API Key，保存后测试连通性。

  3. 在当前世界的仿真页面设置 默认模型和日程模型。

  4. 保存运行配置。

模型字段和连接问题见 模型与运行配置。

选择城市与居民¶

打开 城市，选择已有城市，或输入地名创建城市。在 Agent Studio 查看居民的档案、状态和社会关系，再回到仿真页面选择参与本次运行的居民。

备注

首次运行可以选择少量居民、设置 1 天仿真，先检查模型输出、运行日志和结果目录。

启动仿真¶

  1. 将仿真时长设为 1 天。

  2. 确认居民列表、城市和模型配置，保存后启动。

  3. 在日志中查看进度与居民行动。

  4. 运行完成后进入轨迹回放和居民详情。

使用命令行¶

命令行使用工作区中的运行配置，模型密钥按配置中的环境变量读取。配置完成后：

gaworld run --sim-days 1

更多参数见 命令行界面。

使用 Python 访问结果¶

保持控制台服务运行，在另一个终端执行 Python：

from gaworld.client import GAWorldClient

gw = GAWorldClient("http://127.0.0.1:8766")
print(gw.run_status())

启用账号的部署先登录，操作见 Python 与 HTTP 接口。
