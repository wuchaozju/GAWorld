gaworld.skills.schemas¶

class gaworld.skills.schemas.Skill[源代码]¶

A reusable capability an agent can hold and apply.

变量:

  • skill_id -- Stable identifier; usually the filename basename.

  • name -- Short human-readable title shown in prompts.

  • description -- One-line summary used both for trigger matching and the agent's prompt-time skill list.

  • body -- Free-form Markdown body — the "how to use this skill" detail passed into work-adapter prompts.

  • triggers -- Keyword hints. The registry uses these (plus description and name) for cheap substring matching against action/activity text.

  • source -- "global" for hand-authored library skills, "private" for agent-summarised skills.

  • owner_agent_id -- The agent that owns a private skill (None for global skills).

  • origin -- Optional provenance string (e.g. "consolidation", "seed") — kept for debugging and analysis.

  • created_day -- Simulation day the skill was created, when known.

gaworld.skills.consolidation¶

gaworld.skills.consolidation.summarize_experience_to_skill(agent: dict[str, Any], *, llm: LlmFn, registry: SkillRegistry | None = None, today: int | None = None, lookback_days: int | None = None, min_episodes: int = 4) → Skill | None[源代码]¶

Try to derive one new private Skill from the agent's recent episodes.

Returns the saved Skill on success, or None if no pattern was extracted. Idempotent on the slug: a returned LLM payload whose name slugifies to an existing private skill id is silently overwritten (the LLM is allowed to refine the same skill over time).
