429: the daily model-call quota is used up.

A background job ended in failed / error / stopped.

One connection's worth of state: base URL, operator token, cookies (session and world).

GAWorldClient.wait_job(poll_path: str, *, interval: float = 1.0, timeout: float | None = None) → dict[str, Any][源代码]¶

Poll a …/jobs/{id} route until the job is final; raises JobFailed if it failed.

GAWorldClient.run_job(path: str, body: dict[str, Any] | None = None, *, poll: str | None = None, interval: float = 1.0, timeout: float | None = None) → Any[源代码]¶

Start a job, wait for it, return its result.

The job is polled at <parent of path>/jobs/<id> — the dashboard's layout for every job-starting route (/api/games/rumor/run → /api/games/rumor/jobs/<id>); pass poll for one that differs, with {job_id} where the id goes.

GAWorldClient.events(tables: list[str] | tuple[str, ...] | None = None, timeout: float | None = None) → Iterator[tuple[str, dict[str, Any]]][源代码]¶

Follow /api/events/stream: yields (table, row) for every new Recorder row.

Blocks between rows (the server sends a keep-alive every 15 s); stop by breaking out of the loop. timeout bounds the wait for one line.

HTTP 接口描述¶

运行 Dashboard 后，可读取完整 OpenAPI 文档：

curl http://127.0.0.1:8766/api/openapi.json

文档包含操作名、路径、参数、请求体、响应与访问要求。客户端的 operations() 列出操作，call() 通过 operationId 调用。

独立的 Twin、Agent Relay 和 External Environment 服务接口见仓库的 完整 API 参考。
