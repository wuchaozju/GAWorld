Assemble the six kernel services from CONFIG.

Behavior-compatible with the legacy bootstrap: the EventBus loads the same CONFIG["extensions"] hook declarations HookBus did, and plugin sources (CONFIG["plugins"] + entry points) default to empty/no-op until plugins land in K3.

gaworld.kernel.bus¶

class gaworld.kernel.bus.EventBus(config: dict | None = None)[源代码]¶

Priority-ordered hook dispatcher with observe/collect/filter semantics.

EventBus.on(event: str, fn: Callable, *, priority: int = 0, critical: bool = False) → None[源代码]¶

Register an observer, or a critical state-changing participant.

Critical handlers propagate their original errors immediately. This is for participants whose failure makes continued execution invalid; ordinary third-party observers retain the warning-only boundary.

EventBus.emit(event: str, **context) → list[str][源代码]¶

Observe semantics: notify handlers, ignore return values.

EventBus.collect(event: str, **context) → list[Any][源代码]¶

Contribute semantics: merge every handler's contribution(s).

EventBus.filter(event: str, value: Any, **context) → Any[源代码]¶

Pipeline semantics: value flows through handlers, each may rewrite.

Handlers have signature fn(value, context_dict). Returning None keeps the previous value.
