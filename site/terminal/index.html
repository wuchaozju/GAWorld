// graphical_abstract

城市输入 → 有记忆的智能体 → 反事实对照

城市输入经由具有记忆的智能体,在「有事件 / 无事件」两个世界里分别演化; 两个世界的差异,就是事件影响的估计。

[01]INPUTS 地图 / 政策 / 环境 / 外部信息 — 城市侧的所有变量
[02]AGENTS 51 位居民,每位持有状态 / 记忆 / 关系 / 习惯 — 跨天持续体
[03]LOOP perceive → plan → act → reflect — 每个 tick 的认知循环
[04]WITH_EVENT 同一种子,叠加政策冲击 — 一个世界
[05]WITHOUT 同一种子,不叠加 — 另一个世界
[06]IMPACT Δ(with, without) → 行为轨迹 / 状态演化 / 社会动态 / 对照摘要 — 影响估计

// console_views

功能入口

下面每一项都是控制台里的一个视图,共用同一批居民 / 同一份配置 / 同一条仿真轨迹。

1BUILD · 构建

cities城市给一个地名,自动取地理坐标与 OpenStreetMap 路网。 population人口与群体设定人口结构,生成几百个居民,先按群体低成本试跑。 agent_studio智能体工作台逐个设计具有状态 / 记忆 / 社交 / 目标的数字居民。

2RUN · 运行

dashboard控制台配置 / 运行 / 采访 / 记忆 — 一站式本地仿真面板。 simulation仿真回放按帧回看每个时刻居民在城市中的位置、状态与活动。

3EXPERIMENT · 实验

parallel_worlds平行世界同一批人 / 同一个种子,只换一件事。 cooperation合作任务给一组居民一个共同目标,看他们怎么分工。 survey群体采访把同一问题抛给多个居民,收集结构化答复。 external_system外部系统接外部 LLM / API / 数据源,做联合仿真。

4ANALYZE · 分析

analytics结果分析指标 / 折线 / 雷达 / 事件时间线。 research研究工作台把一次实验写进可复现的 research notebook。

5PLAYGROUND · 游戏场

games互动游戏场辩论 / 灾难 / 谣言扩散 — 三个轻量交互。 docs文档13 个视图的入门与教程。 settings设置语言 / 默认城市 / 性能参数。
