overview · 概览

GAWorld 把城市社会仿真拆成 5 个阶段: build → run → experiment → analyze → playground。 每个阶段对应控制台里的若干视图。下表把 13 个视图按阶段排好: 

# 13 views · 5 stages · 同一批居民 + 同一份配置
1 build    · cities · population · agent_studio
2 run      · dashboard · simulation_replay
3 experiment · parallel_worlds · cooperation · survey · external
4 analyze  · analytics · research
5 playground · games (persuasion / disaster / rumor) · docs · settings

install · 安装

Python ≥ 3.11。本地运行,无构建步骤,无需联网即可查看控制台。

$ git clone https://github.com/<org>/gaworld.git
$ cd gaworld
$ pip install -r requirements.txt
$ python generative_city_sim.py run   # 打开控制台

first_run · 第一次跑仿真

默认人口 51,默认城市 杭州 · 临安。控制台打开后:

  • 进入 /terminal/console.html(或 cream 版 /console)
  • 侧栏 run / dashboard → 看 4 个核心指标
  • 侧栏 run / simulation → 进入 /terminal/simviz.html 逐帧回放
// TIP · LIVE 仿真默认就在跑。控制台右上角会显示 SIM_LIVE · 51 agents · day 14。 想暂停,直接关掉终端进程即可 — 数据会写到 output/state/。

counterfactual · 反事实对照

「同一批居民 / 同一个种子 / 只换一件事」是 GAWorld 的核心姿势。 通过 parallel_worlds 视图同时跑两个世界,然后在 analytics 里看 Δ。 

# 例:拥堵对出行的影响
with_event   = baseline + transit_delay(8min)
without      = baseline
impact       = Δ(with, without) → stress / time_use / mood

city · 造一座城

通过 gaworld.city create 命令创建可复用的城市 bundle,落到 data/cities/<slug>/。 控制台顶部会自动列出已建城市,直接切换即可。

persona · 从真人蒸馏

Agent Studio 的「+ 从真人蒸馏」入口,接受人名或 URL,自动调研 + 提炼 思维框架,落到 output/personas/<slug>/persona.json。 蒸馏与部署是分开的两步 — 部署才会写 seed CSV。

plugin · 写自己的插件

写一个 gaworld.kernel.Plugin 子类,经 CONFIG["plugins"] 或 entry point 装配。新代码只写进 gaworld/ 包,不再加根目录模块。

// WARNING 旧 legacy/ 是 flat 模块的归档,与新代码不互通。导入请走 gaworld.*。

research · 实验写作

research 视图把一次实验写进可复现的 research notebook — 配置 / 事件 / 种子 / 关键指标全在;Markdown 可直接导出。

playground · 互动场

控制台 games 视图聚合了三个轻量交互:

  • persuasion — 辩论,在 turn 限制内反复说服
  • disaster mode — 一批居民走完一个灾难阶段,结构化作答
  • rumor spread — 谣言沿社会网络扩散,报告扩散树

完整文档请看 cream 版的 /dashboard/docs.html, 或在控制台内的 docs 视图里搜索。
