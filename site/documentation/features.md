# 功能总览

GAWorld 将居民行为与城市环境放在同一仿真中。下表按使用目的列出主要功能与控制台入口。

## 居民与社会关系

| 功能 | 可以做什么 | 从哪里开始 |
| --- | --- | --- |
| 居民档案与人格 | 设置身份、职业、初始状态和大五人格 | Agent Studio |
| 记忆与目标 | 查看经历、记忆、长期目标及其变化 | 居民详情 |
| 家庭与社会关系 | 查看家庭责任、朋友与社交网络 | Agent Studio、关系面板 |
| 访谈 | 向居民提问，收集回答并追问 | 访谈、群体采访 |

## 城市与环境

| 功能 | 可以做什么 | 从哪里开始 |
| --- | --- | --- |
| 城市与地图 | 按地名创建城市，配置空间与居民 | 城市 |
| 物理环境 | 让天气、空间与局部环境参与行动决策 | 仿真配置、轨迹回放 |
| 经济系统 | 观察收入、支出、储蓄、债务与宏观状态 | Analytics、外部系统 |
| 事件与干预 | 设置人生事件、环境变化与政策 | 人生事件、平行世界 |

## 技能与工作

**技能系统**使用 Markdown 技能库，为智能体提供可复用的操作知识。全局技能保存在 `data/skills/`，居民的私有技能可保存在运行输出的 `memory/agent_<id>_skills/` 中。技能的注入与提炼由相应配置项控制。

**真实工作**把工作请求交给任务队列和适配器执行。启用后，可以在 `work/` 中查看任务状态与产物。运行前需要配置适配器及其依赖服务。

(research)=
## 研究与对照

**研究工作台**用于组织研究问题、候选方案、预注册与实验运行。**平行世界**从共同基线建立多个世界，设置不同事件，再比较各组轨迹和指标。

**群体模拟**提供人口合成与群体近似。使用时按研究问题检查对应验证结果，并保存人口参数与抽样设置。

完整的功能与配置项可查阅仓库中的 [功能特性总览](https://github.com/wuchaozju/GAWorld/blob/main/docs/FEATURES.md)。
