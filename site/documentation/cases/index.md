# 案例总览

从已有实验出发，查看 GAWorld 如何组织研究问题、设置比较条件、保存输出并分析结果。

| 案例 | 研究问题 | 可以查看什么 |
| --- | --- | --- |
| [已有仿真实验](simulation-records.md) | 信息传播、观点极化、记忆、经济与政策如何影响居民？ | 实验设计、历史运行记录与原始报告 |
| [经典行为实验](classics.md) | 居民在不同题面与博弈条件下如何选择？ | 六个范式、运行命令与配对判定 |
| [需求估计实验](demand.md) | 价格和提示词中的情境信息如何影响购买回答？ | 五种条件、需求曲线与诊断指标 |

## 按研究任务选择

- **先读已有结果**：从“已有仿真实验”选择一个主题，按条件设置、实际运行范围和输出指标阅读报告。
- **做一次独立问答实验**：经典行为实验与需求估计实验直接读取居民档案，由专用模块组织模型调用。
- **观察干预后的连续变化**：使用 [研究工作台](../research.md) 与 [平行世界](../parallel-worlds.md)，跟踪居民行动、状态和记忆。

## 配套教学案例

用户指南中的 [补贴通告对照实验](../parallel-worlds.md) 提供完整配置，比较基准、补贴通告与例行通告三个条件。[研究工作台](../research.md) 继续演示协议检查、跨种子重复和假设判定；[结果分析](../results.md) 提供可下载的 CSV 与绘图脚本。

这组配套文件使用标明来源的合成教学数据，适合先练习报告阅读和分析流程，再换成自己的运行结果。
