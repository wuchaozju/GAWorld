Graphical Abstract

研究总览图

城市输入经由具有记忆的智能体，在“有事件 / 无事件”两个世界里分别演化； 两个世界的差异，就是事件影响的估计。

What it is for

你可以用它做什么

01

政策前后对照

并行运行“有事件 / 无事件”两组仿真，量化压力、情绪、出行等指标的差异。

02

跨天经验积累

居民不是一次性脚本角色，而是会形成习惯、关系与日常行为倾向的持续体。

03

可扩展社会实验

通过插件、配置和外部环境服务快速接入经济、环境、外部信息等新模块。

Console views

功能入口

下面每一项都是控制台里的一个视图。它们共用同一批居民、同一份配置和同一条仿真轨迹—— 按下面的顺序走，就是一次完整的研究。

1构建Build

Cities 城市

给一个地名，自动取地理坐标与 OpenStreetMap 路网，造一座城。

 Population 人口与群体

设定人口结构，生成几百个居民，先按群体低成本试跑。

 Agent Studio 智能体工作台

逐个设计具有状态、记忆、社交与目标的数字居民。

2运行Run

Dashboard 控制台

配置、运行、采访、记忆——一站式本地仿真面板。

 Simulation 仿真回放

按帧回看每个时刻居民在城市中的位置、状态与活动。

3实验Experiment

Cooperation 合作任务

编组居民、委派角色，沿计划与产物轨道观察一项真实合作。

 Group Interview 群体采访

跨城市问一群人同一个问题，统计他们的选择，导出一份完整文档。

 External 外部系统

货币怎么流、环境抛出了什么事件——观察它们，而不是直接改。

4分析Analyze

Analytics 结果分析

状态变化、经济轨迹、社交网络、行为分布、事件时间线。

 Research Workbench 研究工作台

给一个研究想法或一篇论文，由模型分析如何用 GAWorld 实现它，产出实施方案；「平行世界」页签做多分支反事实实验与因果推断。

5系统System

Settings 配置

全部配置项集中在一处，每一项都写清了它管什么。

 Docs 文档

直接渲染仓库 docs/ 里的文档本身，不是复制出来的副本。

Counterfactual run

事件影响评估流程

使用 compare-event 子命令，系统会在隔离目录下自动重置、并行执行、汇总差异并生成报告。 在控制台里，同样的事情由研究工作台的「平行世界」页签完成，还能一次开 2–8 个世界、跨种子重复，并给出带置信区间的效应估计。

  • comparison_summary.md自动差异总结
  • comparison_metrics.csv指标 delta 明细
  • agent_*_episodes.jsonl结构化经验片段
python generative_city_sim.py compare-event \
  --event-name "临时交通限行" \
  --event-description "主干道限行导致通勤时间上升" \
  --event-day 2 \
  --event-time 09:00 \
  --sim-days 3 \
  --llm-provider openai_gpt \
  --seed 42
