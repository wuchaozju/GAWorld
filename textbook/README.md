## 全书教学特色

1. **理论与方法论并重**：第 19 章专门讨论社会仿真的认识论、方法论、因果归责。
2. **多平台覆盖**：第 20 章对比 NetLogo、Repast、Mesa、AnyLogic、GAWorld 等多个平台。
3. **跨学科视角**：第 22 章展示 9 个跨学科经典案例。
4. **经典与现代结合**：第 3 章深入分析 8 个经典案例（Schelling 到 EpiSimdemics）；第 13-16 章展示 GAWorld 现代 LLM 范式。
5. **每个案例都给出可运行命令**：读者在本地装好 GAWorld 后可直接复制运行。
6. **网络科学深度**：第 21 章从理论视角讨论小世界、无标度、网络效应。
7. **可读指标**：所有图表都带白话说明，参考 GAWorld "外部系统"面板的 hover 注释风格。

## 教材的核心思想

- **社会仿真是一种跨学科方法论**，不是某个工具的功能。
- **经典案例与现代案例并重**，覆盖 70 年历史与最新前沿。
- **多平台并存**，GAWorld 是 LLM 时代的代表，但不是唯一选择。
- **哲学深度足够**，认识论、方法论、因果归责都有深入讨论。
- **跨学科应用广泛**，从人类学到经济学到组织行为学都有应用。
- **理论与技术均衡**，既讲清原理，也给出可运行代码。
