## 全书教学特色

1. **每个案例都给出可运行命令**：读者在本地装好 GAWorld 后可直接复制运行。
2. **思想 / 技术 / 案例交替**：每三章一个节奏单元，避免"看代码累"或"纯讲理论空"。
3. **预注册意识**：所有案例都按预注册 → 实验 → 报告 的规范流程写。
4. **可读指标**：所有图表都带白话说明，参考 GAWorld "外部系统"面板的 hover 注释风格。

## 写作与排版约定

- **Markdown 变体**：CommonMark + GFM 表格 + Mermaid 图（流程/架构/序列图）+ PlantUML（UML 时序图）
- **代码块**：Python ≥ 3.11；命令行默认在 GAWorld 根目录执行
- **引用**：脚注式 `[^n]` + 章末 References；核心论文给出 arXiv 链接
- **中文规范**：术语首次出现给出英文原文与缩写；机构名、LLM 名保留原拼写
- **图表编号**：每章独立编号（图 4.2、表 4.1），便于抽取单章讲义
- **行文口吻**：教材体（不是论文体）；第二人称"读者"为主，避免"我们认为"
- **AI 痕迹**：避免"否定式排比"、"三段式法则"等 AI 写作特征；保持苏东坡式"该长则长、该短则短"
