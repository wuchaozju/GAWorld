# 第 18 章　仿真不是一切——局限、伦理与 2026 年后的方向

> 这是本书的收官章节。社会仿真不是万能的方法——它有明确的局限,涉及严肃的伦理问题,也正在被新方法、新工具重新定义。这一章讨论三件事:仿真做不了什么、伦理边界在哪、2026 年后这个领域会怎么走。读者读完本章,应该对"什么时候用仿真、什么时候不用"形成清晰的判断。

---

## 18.1　LLM 仿真的偏置与黑箱

LLM 给社会仿真带来了真实感,也带来了两个新问题:**偏置**与**黑箱**。

### 偏置的类型

LLM 的训练数据带有显著的文化偏见,主要是英语、北美、都市中产视角。这意味着:

**地域偏置**:LLM 对"农村""县城""三四线城市"的理解往往粗糙。仿真中国西部农村居民的行为时,LLM 可能会给出现代都市白领的反应。**应对**:用本地化语料微调(成本高)、或用规则系统替代关键决策。

**文化偏置**:LLM 对"集体主义 vs 个人主义""高语境 vs 低语境"等文化差异敏感度不够。仿真东亚社会的"礼貌"行为时,LLM 可能给得太直接。**应对**:在 prompt 里明确强调文化背景,或用文化特定的 LLM(如日文优化模型)。

**价值偏置**:LLM 的训练里有特定的"政治正确"——种族平等、性别平等、环境保护等。如果仿真研究需要"非政治正确"的场景(如某些歧视行为),LLM 会回避。**应对**:用 red-teaming prompt 强制输出,或承认局限——这种场景用纯规则系统可能更合适。

### 黑箱问题

LLM 的决策路径不可追溯——同一个 prompt,LLM 可能给出不同答案,而且我们不知道"为什么是 A 不是 B"。这对社会仿真的可信度是巨大挑战:

**可解释性损失**:传统 ABM 的决策是规则的,可以逐行追溯。LLM ABM 的决策是神经网络的,只能黑箱接受。

**可复现性损失**:同一 prompt 不同次调用可能给出不同答案,即使温度=0 也可能有微小差异(底层模型的浮点运算不严格确定)。

**可证伪性损失**:如果模型可以解释一切(包括相反的),它就不可证伪。

### 应对策略

GAWorld 用三种策略应对:

1. **多裁判投票**:让 3 个 LLM 独立决策,少数服从多数。
2. **结构化输出**:强制 JSON 格式,便于校验。
3. **配置触发器 + 启发式回退**:LLM 失败时回退到规则系统。

这些策略能缓解问题,但不能完全消除。读者做研究时,**必须**承认 LLM 的局限,不能把它当成"完美的人类模拟器"。

## 18.2　虚假关联、过拟合与"事后解释"

社会仿真的另一个陷阱是"虚假关联"和"事后解释"——它们不是 LLM 的问题,是任何建模方法都可能犯的错。

### 虚假关联

仿真里的两个变量看起来相关,实际上是因为共同的原因,而不是因果。例如:

- 仿真显示"咖啡消费高的人幸福感也高"——这可能是因为"高收入"同时导致了两者。
- 仿真显示"社交频次高的人健康好"——这可能是因为"性格外向"同时导致了两者。

**应对**:用预注册 + 反事实 + 中介分析,排除共同原因。

### 过拟合

仿真模型往往有几十个参数,容易过拟合到特定数据集。例如:

- 用 5 个真实数据点校准 20 个参数,可能跑出完美匹配,但推广性差。
- 用一组 prompt 测试另一个 prompt,可能跑出强烈相关,但换 prompt 后关系消失。

**应对**:用**留出集**(holdout set)——校准用前 70% 数据,验证用后 30%。如果验证集表现差,模型过拟合。

### 事后解释

跑完仿真,看到结果,然后"解释"为什么是这样——这是经典的"事后解释"陷阱。例如:

- 跑出"限行令减少驾车 24%",然后声称"这是因为公共交通被强制使用"
- 但仿真里可能有 10 个机制同时作用,我们没法说"是哪一个"

**应对**:用**机制追溯**(mechanism tracing)——从宏观结果追溯到微观机制。看哪些 agent 的哪些决策贡献了结果,贡献多少。如果不能清晰追溯,就是事后解释。

### 自我警醒的几个问题

跑完仿真后,读者应该问自己:

1. **我能不能预测这个结果?** 如果能,仿真只是验证,不是发现。
2. **我能不能给出替代解释?** 如果能,我的结论不稳健。
3. **仿真里有没有我"调参"的部分?** 如果有,要标注这是"调参结果"。
4. **如果换种子,结论变吗?** 如果变,结论不稳定。

这些问题答不上来,说明仿真有"虚假繁荣"的风险。

## 18.3　伦理:被仿真者、知情同意与社会影响

社会仿真涉及的伦理问题,比一般人想象的要严肃。

### "被仿真者"的伦理

仿真里有"被仿真者"——他们是谁?他们的行为、身份、记忆都被模型化和再现。这涉及:

- **代理人问题**:仿真一个真实城市的居民,他们的"虚拟代理人"由谁授权?城市管理部门?居民个人?
- **形象问题**:仿真里的居民可能被赋予他们本人不认可的行为(比如"囤物资""歧视邻居")。这是不是对他们形象的伤害?
- **记忆问题**:仿真里的居民会形成"记忆",如果这些记忆和真实人的记忆相似,会不会被误以为是真实记录?

GAWorld 在工程上的处理:
- 默认生成的居民是**虚构**的(从联合分布抽样,不对应真人)
- 用户**主动**输入真人(Persona Distillation)时,需要明确授权
- 输出会被标记"虚拟人物",不冒充真人

### 知情同意

仿真研究的"被研究者"不是真人,而是仿真 agent——这是否意味着不需要知情同意?

**严格说,是的**——仿真的 agent 没有真实的"知情"能力。但有两个问题需要警惕:

1. **如果仿真涉及真人**——比如"仿真上海居民对某政策的反应",这里的"上海居民"是真人群体。即使每个具体的 agent 是虚构的,结论可能被解读为对真实群体的描述。这就有**群体同意**的问题。
2. **如果仿真涉及敏感群体**——比如"仿真某少数民族的代际流动",这里可能涉及**强化刻板印象**的风险。

**应对**:研究者应该明确"这是仿真结论,不是对真实群体的描述",并避免涉及敏感群体的负面行为模拟。

### 社会影响

仿真结论一旦发表,可能被用于政策决策、商业决策、媒体传播。这带来"双重效应"风险:

- **好的社会影响**:政策仿真帮助决策者预演政策效果,减少试错成本。
- **坏的社会影响**:仿真结论可能被误用——"GAWorld 仿真显示 X 群体更暴力",这种结论可能强化偏见。

**应对**:研究者在发布结论时,**必须**附上"使用边界"声明,告诉读者"这是仿真,不是真实,不能用于歧视性决策"。

GAWorld 的研究工作台在生成报告时,自动加一段"使用声明":

```
本仿真结论仅用于学术研究,不能用于:
- 对真实群体的歧视性描述
- 政策决策的唯一依据
- 商业决策的唯一依据
真实决策应基于真实数据 + 多元方法,仿真只是辅助工具之一。
```

## 18.4　从仿真到孪生:从离线走向同步

社会仿真有一个新的发展方向:**仿真孪生**(Simulation Twin)——把仿真从离线分析工具,变成与真实系统同步运行的"数字孪生"。

### 仿真孪生的概念

传统仿真:**离线**,先运行,后分析。

仿真孪生:**在线**,实时同步。城市运行的状态(交通、人口、事件)实时流入仿真,仿真结果实时回流到城市决策系统。

**例子**:
- 杭州的"城市大脑"——基于实时数据做交通调度,某种程度上就是仿真孪生。
- 银行的"压力测试"——用仿真模拟金融危机,实时评估银行风险。
- 医院的"数字孪生"——用仿真优化手术排程、床位分配。

### GAWorld 的孪生化尝试

GAWorld 在 2025–2026 年开始尝试孪生化:

- **实时数据接入**:从交通部门、统计局 API 拉取实时数据,更新仿真参数。
- **决策辅助系统**:仿真结果实时推送给决策者,作为决策参考。
- **回放验证**:用真实发生的事件验证仿真预测,不断校准模型。

但仿真孪生有几个**严肃的挑战**:

1. **延迟问题**:实时数据接入有延迟,仿真结果可能"过时"。
2. **反馈环风险**:仿真结果影响决策,决策影响真实系统,真实系统又影响仿真输入——这是**反馈环**,可能导致意外行为。
3. **责任问题**:如果仿真孪生建议"关闭医院",结果医院真的关了,事后发现决策错了——谁负责?

### 读者做孪生研究的建议

如果你想做仿真孪生研究:

1. **小步迭代**:从离线仿真开始,验证可行性后再向孪生演化。
2. **明确决策边界**:仿真只是参考,人类决策者必须有最终决定权。
3. **反馈环监控**:密切监控"决策→真实系统→仿真输入"的反馈环,防止意外放大。
4. **应急回退机制**:如果仿真出错,能立刻切换到纯人工决策。

## 18.5　多模态、具身与真实接口

社会仿真的未来方向之一是**多模态**——结合图像、视频、声音、传感器数据。

### 多模态仿真的可能性

- **视觉仿真**:仿真里的居民能"看到"真实环境的图像(摄像头、街景),做出更真实的反应。
- **听觉仿真**:仿真里的居民能"听到"真实环境的声音(警报、音乐、对话)。
- **触觉仿真**:仿真里的居民能"触摸"真实物体(机器人仿真)。
- **多模态融合**:综合视觉、听觉、触觉的仿真。

### 具身智能与社会仿真

**具身智能**(embodied AI)是 2024 年后的热点——把 AI 装进物理实体(机器人、自动驾驶车),让它在真实世界中行动。如果仿真里的"居民"有了具身,就能产生真实的社会互动——这模糊了仿真和现实的边界。

**例子**:用机器人作为"仿真居民",在真实社区里和其他真人互动。这已经不是仿真了,是真实实验。但它可以被仿真框架管理(可控、可复现、可回退)。

### GAWorld 的多模态规划

GAWorld 在 2025 年开始支持多模态输入:

- **图像理解**:居民 prompt 里可以包含图片(街景、商品图)。
- **视频理解**:长期视频可以提取关键场景作为仿真输入。
- **音频理解**:对话录音可以作为"他人说过的话"输入仿真。

但多模态也带来新问题:**幻觉**。LLM 在多模态下也会"看到"不存在的东西、"听到"不存在的声音。**应对**:用规则系统做图像/音频的事实校验,LLM 只做高层理解。

## 18.6　社会仿真在 2026 年后的方向

展望 2026 年后,社会仿真有三个明显的发展方向:

### 方向一:大规模真实数据校准

社会仿真最大的局限是"和真实数据脱节"。2026 年后,随着开放数据(政府数据、社交数据、商业数据)越来越多,仿真模型能用真实数据校准,而不是用联合分布抽样。

**机会**:政府开放数据(统计、交通、教育、医疗)的广泛可得,让"真实校准"成为可能。

**挑战**:数据隐私。校准需要大量个人级数据,这和 GDPR / 个人信息保护法冲突。**应对**:用合成数据 + 差分隐私技术。

### 方向二:多学科融合

社会仿真正在和越来越多学科融合:

- **流行病学**:传染病仿真已经成熟,COVID 后加速发展。
- **气候科学**:气候—社会耦合仿真刚刚起步。
- **神经科学**:脑科学 + 行为仿真,理解个体决策。
- **城市规划**:城市仿真 + 真实规划决策。
- **金融**:金融仿真 + 压力测试 + 监管。

### 方向三:社会仿真作为基础设施

社会仿真可能成为"社会科学基础设施"——像高性能计算一样,任何社会科学家都能调用。

**机会**:仿真平台(GAWorld、NetLogo、Repast)的用户友好化,让非工程背景的研究者也能用。

**挑战**:可信度——一旦仿真成为基础设施,错误仿真的社会影响会放大。**应对**:建立仿真可信度标准、第三方审计、错误检测。

### GAWorld 的 2026 后路线图

GAWorld 的公开路线图:

- 2026 年:完善群体模式 + 验证门 + 平行世界功能
- 2027 年:多模态输入 + 仿真孪生试点
- 2028 年:跨学科融合(气候、社会、神经) + 开放数据校准
- 2029 年:基础设施化 + 第三方审计 + 错误检测

读者如果长期做仿真研究,应该关注 GAWorld 的路线图——它代表了社会仿真领域的工程前沿。

## 18.7　回到"为什么"

这一章在收尾,我们回到第 1 章的核心问题:**为什么社会科学家要做仿真?**

第 1 章的答案是"跨越解释性鸿沟"。这一章补充:**仿真不是万能的,有偏置、有黑箱、有虚假关联、有伦理风险**。

所以,做仿真研究的人应该:

1. **承认局限**:仿真是工具,不是答案。
2. **承认偏置**:LLM 不是中立的,仿真也不是。
3. **承认责任**:仿真结论有社会影响,研究者有责任声明其使用边界。
4. **承认失败**:跑不出结论的仿真也是结果——说明"这个问题不能用仿真回答"。

这是社会仿真作为研究方法的"诚实工程学"。## 18.9　思考题

1. **评估你自己的仿真研究**:它有哪些偏置、黑箱、虚假关联风险?如何应对?
2. **设计一个伦理声明**:你的仿真结论应该怎样写使用边界?
3. **展望你未来的仿真研究**:5 年后、10 年后,你会做什么样的仿真?
4. (进阶)**为社会仿真领域写一份"行业规范"**:可信度标准、第三方审计、错误检测应该怎么设计?

### 18.11 扩展:LLM 仿真的深入讨论

### 18.11.1　LLM 训练的伦理

LLM 训练数据涉及:

- 版权问题(用谁的文本训练)
- 隐私问题(个人信息是否被记住)
- 偏见问题(文化、性别、种族)
- 劳动问题(标注工人的工作条件)

社会仿真研究者应该关注这些问题。

### 18.11.2　LLM 的环境影响

训练大型 LLM 的能耗巨大:

- GPT-4 训练:估计 5000+ 吨 CO2
- 一次 LLM 调用:~ 1g CO2
- 大规模仿真可能产生显著碳足迹

研究者应该考虑环境影响。

### 18.11.3　LLM 仿真的长期价值

LLM 仿真带来的长期价值:
