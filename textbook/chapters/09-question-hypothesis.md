# 第 9 章　从研究问题到仿真假设

> 有了智能体、环境、网络、LLM、运行系统——技术层全部到位。但**做研究不是从"我有工具"开始,而是从"我有研究问题"开始**。这一章讨论社会仿真作为研究方法的全流程第一步:如何把一个模糊的研究问题,变成可被仿真验证的、可证伪的、有可测量指标的假设。读完本章,读者应该能用预注册协议的格式写出自己的第一个仿真研究计划。
>
> **本章补充:理论深度视角**。除了方法流程,本章还讨论:
> - **科学问题与哲学问题的区分** (Reichenbach 1938)
> - **假设的逻辑结构** (Hypothesis Logic, Popper 1959)
> - **变量类型学** (Variable Typology, Lazarsfeld 1964)
> - **预注册运动的科学哲学背景** (Open Science 运动)
> - **仿真假说的特殊性**——它们如何与理论假说和实证假说区分

## 9.1　什么适合仿真:复杂机制、多变量、非线性、可重复

### 9.1.1　理论背景:科学问题的分类

不是所有社会现象都适合用仿真研究。社会仿真作为研究方法有明确的适用边界,源于科学问题的分类:

- **Reichenbach (1938)** 区分"发现语境"(context of discovery)和"验证语境"(context of justification)。仿真可以同时在两个语境中工作。
- **Lakatos (1970)** 区分"成熟科学"和"过渡科学"。成熟科学有"硬核 + 保护带"——仿真可以成为"保护带",保护核心假说不被反例推翻。
- **Kuhn (1962)** 区分"常规科学"和"范式转换"。仿真在"常规科学"阶段最有效,在"范式转换"阶段则可能创造新范范。

社会仿真在哪一类研究中有效?

- **机制识别**:验证因果机制(最擅长)
- **反事实生成**:生成不能观测的反事实(独特价值)
- **长期预测**:在长期仿真下预测趋势(中等)
- **伦理不可实验**:不能用真人实验的场景(独特价值)
- **微观-宏观链接**:从个体行为推演宏观模式(核心价值)

不是所有社会现象都适合用仿真研究。社会仿真作为研究方法,有明确的适用边界。

**适合仿真的**:

- **机制识别问题**:同一现象有多个互相竞争的理论,你想知道哪个机制能复现宏观。例如"为什么限行令效果递减",有"替代效应""适应效应""网络效应"三个理论。
- **反事实评估问题**:你想知道"如果当初做了 X 而不是 Y,结果会怎样"。例如"如果限行令没有实施,出行量会继续增长多少"。
- **长期动态问题**:你想知道 5 年、10 年后的趋势。例如"延迟退休政策对劳动力市场的影响"。
- **多变量交互问题**:你关心的现象受 5+ 变量影响,数学建模不可解析。例如"气候政策 × 经济冲击 × 技术变化 × 社会态度"四维交互。
- **不可实验问题**:伦理或现实限制让你无法做真人实验。例如"疫情封控的最优时长"。

**不适合仿真的**:

- **简单关联问题**:两个变量的相关/因果,直接用统计就行。例如"收入和幸福感的关系",仿真反而过度复杂。
- **小样本问题**:样本量 < 30 的现象,统计推断把握度不够,仿真也救不了。
- **历史唯一性问题**:只发生过一次的事件,没有"反事实"可比。例如"拿破仑战争的影响",仿真的反事实不成立。
- **意义建构问题**:现象的核心是"人对意义的赋予",仿真只能逼近不能替代。例如"宗教皈依体验"。
- **价值判断问题**:涉及"应当怎么做",仿真只能给"会发生什么"。例如"减税是否道德"。

读者做研究时,先问自己:**我要研究的问题在哪一类?** 这决定了你应不应该用仿真。

### 一个具体的判断练习

假设你要研究"远程办公对城市碳排放的影响"。这是适合仿真的吗?

- 涉及多个变量:通勤、出行方式、办公建筑能耗、家庭能耗、消费模式…… ✓ 复杂机制
- 可以反事实:有远程办公 vs 无远程办公 ✓ 反事实评估
- 可以长期仿真:10 年、20 年视角 ✓ 长期动态
- 不能直接做实验 ✓ 不可实验
- 多变量交互:政策 × 城市 × 行业 × 家庭 ✓ 多变量

**结论:非常适合仿真**。

## 9.2　预注册协议:把假设写成可证伪的形式

社会仿真研究最容易出的问题是**事后解释**——跑完仿真,看到结果,然后声称"这正好证明了 X 理论"。这是伪科学的标准反模式。

避免它的工程方法是**预注册**(pre-registration):在跑仿真之前,把假设、指标、判定规则写下来,跑完之后**只能按预注册的规则判定**,不能临时改假设或指标。

GAWorld 的"研究工作台"实现了完整的预注册流程:

```
[1] 研究问题:用一句话描述
[2] 条件:平行世界的差异(每个世界一个事件表)
[4] 假设:每条假设包含:
    - 指标(从可测量目录选)
    - 两个条件(世界 A vs 世界 B)
    - 方向(支持 H1 / 反对 H1 / 不显著)
    - 最小可观测效应
[5] 跑前检查:指标是否在目录中、调用量是否在预算内
[6] 批准:copilot 模式在这里停下
[7] 跑实验:每个种子 × 一次世界
[8] 判定:每条假设 → supported / contradicted / inconclusive / unmeasured
[9] 报告:预注册在前,结果在后,严格按规则解读
```

### 一个完整的预注册示例

研究问题:**限行令对城市出行行为的影响**。

```
条件(平行世界):
  W1: control(不实施限行)
  W2: limit_weekday(工作日按尾号限行)
  W3: limit_with_subsidy(限行 + 公共交通补贴)

假设:
  H1: 限行令减少私家车出行
      指标: car_trips_per_capita(代表每日人均驾车次数)
      条件对比: W2 vs W1
      方向: car_trips_per_capita(W2) < car_trips_per_capita(W1)
      最小可观测效应: -10%(即限行后人均驾车次数减少至少 10%)

  H2: 限行令 + 补贴增加公共交通客流
      指标: public_transit_users(代表每日公交+地铁客流总量)
      条件对比: W3 vs W2
      方向: public_transit_users(W3) > public_transit_users(W2)
      最小可观测效应: +15%

跑前检查:
  ✓ car_trips_per_capita 在可测量目录中
  ✓ public_transit_users 在可测量目录中
  ✓ 三个世界调用量预算: ~5 万次 LLM 调用,可接受

批准:✓

实验:
  跑 3 个世界 × 5 个种子 = 15 次仿真
  每个仿真: 1000 人 × 180 天

判定:
  H1: 跑完后看 W2 vs W1 的 car_trips_per_capita
      若 W2 减少 ≥ 10% → supported
      若 W2 减少 < 10% 但 > 0 → inconclusive
      若 W2 反而增加 → contradicted
```

这个预注册协议是 GAWorld 研究工作台的"标准模板"。读者做自己的研究时,应该严格按这个格式写——不要临时改假设,不要事后选指标,不要"看到结果再说"。

## 9.3　效应量、最小可观测效应与样本量

预注册里有两个关键参数:**最小可观测效应**(Minimum Detectable Effect, MDE)和**样本量**(sample size)。

**效应量**(effect size)是衡量"差异有多大"的统计量。常用指标:

- **Cohen's d**:两组均值差 / 合并标准差。0.2 = 小,0.5 = 中,0.8 = 大。
- **相对差异**:`(mean(B) - mean(A)) / mean(A)`,单位是百分比。
- **绝对差异**:`mean(B) - mean(A)`,单位是指标原值。

**最小可观测效应**(MDE)是你"愿意接受"作为"有效果"的最小效应值。设定太大会漏掉真实的小效应;设定太小会被噪声干扰。GAWorld 的默认规则:

- 收入、消费、出行等高频变量:MDE = 5%
- 态度、情绪等低频变量:MDE = 10%
- 网络结构等结构变量:MDE = 15%

**样本量**(sample size)在这里指"多少个仿真世界"。仿真研究里,样本量 = 世界数 × 种子数。

- 5 个世界 × 3 个种子 = 15 次仿真
- 3 个世界 × 5 个种子 = 15 次仿真

这两种设计的信息不同:**多个世界看条件效应,多个种子看随机变异**。通常**3 条件 × 5 种子**是好的起点——既能看到条件效应,也能估计随机变异。

### 一个 MDE 与样本量的练习

假设你要验证"限行令减少人均驾车 10%":

- 1000 人 × 180 天,每个仿真产生 ~180 × 1000 个 car_trips 数据点
- 3 个种子 × 2 个条件 = 6 次仿真
- 总数据点: ~180 × 1000 × 6 = 108 万

这么大的样本量,统计上几乎肯定能检测到 10% 的差异。但问题是:**这个 10% 在现实里有没有意义?**——1000 人 × 180 天跑出来的 10% 差异,可能对应真实城市 1 个月内的 1% 差异。所以仿真里的"显著性"和现实里的"意义性"是两个不同概念,读者写论文时要把它们都写清楚。

## 9.4　对照组、安慰剂与平行世界

仿真的"对照组"有三种形态:

**形态一:对照世界**(control world)。一个完全不做干预的"基线"世界,所有变量都在自然演化。W1 通常就是对照。

**形态二:安慰剂世界**(placebo world)。一个"虚假干预"的世界——比如"宣布但不实施"限行令、或"在另一个不相关领域"实施干预。安慰剂世界用于检测"是不是事件本身的影响,而非事件的内容"。

**形态三:平行世界**(parallel world)。多个不同干预的并行,每个有不同的政策/事件。平行世界用于"哪种政策更有效"。

GAWorld 的实现:

```
--spec worlds.json:
{
  "worlds": [
    {"name": "control", "events": []},
    {"name": "placebo", "events": [{"name": "fake_policy", ...}]},
    {"name": "limit_weekday", "events": [{"name": "limit_weekday", ...}]},
    {"name": "limit_with_subsidy", "events": [
      {"name": "limit_weekday", ...},
      {"name": "transit_subsidy", ...}
    ]}
  ]
}
```

跑完 4 个世界 × 5 个种子,得到 20 次仿真结果。读者分析时:

- 哪个条件平均效应最大?
- 安慰剂效应是否显著?
- 不同种子下的效应是否稳定?

这三条问题决定了"结论可信度"。

### 9.4.5　深度:对照组设计的"五个原则"

设计对照组的五个原则:

**原则一:对照组应"等价"**

- 对照组与处理组除处理外应完全相同
- 例:同样年龄、性别、教育、收入

**原则二:对照组应"自然"**

- 不要人为构造对照组
- 例:用真实数据,不用"假想对照组"

**原则三:对照组应"有差异"**

- 对照组与处理组有足够差异,才能对比
- 例:对照组 = 政策实施前;处理组 = 政策实施后

**原则四:对照组应"可重复"**

- 对照组在论文里要能完整描述
- 例:详细说明"对照组如何抽样"

**原则五:对照组应"有理论"**

- 选对照组要基于理论,而非方便
- 例:为何选 A 而不是 B 作为对照

学生做研究时,严格按这五条设计对照组,避免"对照组任意"的问题。

## 9.5　可测量指标目录

社会仿真需要一个"指标目录"(metrics catalog)——所有可被自动测量的指标清单。GAWorld 的指标目录在 `output/metrics/catalog.json`,目前包含 200+ 指标,分 8 大类:

**经济类**:个人收入、消费、储蓄、负债、净资产、流动性、就业状态
**出行类**:每日出行次数、出行距离、出行方式、通勤时间、机动车使用
**社交类**:每日接触人数、关系强度均值、社交多样性、孤岛度
**心理类**:情绪均值、压力均值、幸福感指数、焦虑指数
**行为类**:决策选择分布、行动频次、活动多样性
**网络类**:网络密度、平均路径长度、聚类系数、连接性
**认知类**:信息量、技能熟练度、学习曲线
**宏观类**:基尼系数、就业率、GDP、增长率、社会信任

读者做研究时,**只能从指标目录里选假设**。不能"想看什么指标就让仿真出什么指标"——这是事后选择,会显著抬高假阳性。

### 一个完整的"假设 → 指标"映射

以限行令案例为例:

| 假设 | 指标 | 条件对比 | 方向 | MDE |
|---|---|---|---|---|
| H1 限行减少私家车出行 | car_trips_per_capita | W2 vs W1 | ↓ | -10% |
| H2 限行 + 补贴增加公交 | public_transit_users | W3 vs W2 | ↑ | +15% |
| H3 限行影响低收人家庭更多 | low_income_car_trips | W2 vs W1 | ↓ | -15% |
| H4 限行增加步行和自行车 | walk_bike_trips | W2 vs W1 | ↑ | +8% |

这种"假设 → 指标"的显式映射,是预注册协议的核心内容。读者写论文时,要严格按这个表执行。

## 9.6　一个真实研究的预注册示例:公共图书馆的代际影响

让我们用一个真实的研究问题作为本章的总结——研究"公共图书馆的使用对儿童学业成就的代际影响"。

**研究问题**:父母在儿童时期使用公共图书馆,是否会增加其子女的学业成就?

**预注册协议**:

```
条件(平行世界):
  W1: control(无公共图书馆影响)
  W2: parent_library_low(父母儿童时期低图书馆使用)
  W3: parent_library_high(父母儿童时期高图书馆使用)

假设:
  H1: 父母儿童时期高图书馆使用 → 子女学业成就更高
      指标: child_education_attainment(子女 18 岁时的学历)
      条件对比: W3 vs W1
      方向: child_education_attainment(W3) > child_education_attainment(W1)
      MDE: +0.5 个学历等级(小学,初中,高中,大专,本科,硕士,博士)

  H2: 父母儿童时期高图书馆使用 → 子女成年后更可能成为图书馆用户
      指标: child_library_use_rate(子女成年后图书馆使用率)
      条件对比: W3 vs W1
      方向: child_library_use_rate(W3) > child_library_use_rate(W1)
      MDE: +20%

  H3: 父母图书馆使用的影响部分通过家庭文化资本中介
      指标: home_culture_index(家庭文化资本指数,基于藏书量、讨论频次等)
      条件对比: W3 vs W1
      方向: home_culture_index(W3) > home_culture_index(W1)
      MDE: +15%

跑前检查:
  ✓ 所有指标在目录中
  ✓ 调用量预算可接受
  ✓ 仿真时长: 25 年(跨代际)

实验:
  3 条件 × 5 种子 = 15 次仿真
  每个仿真: 1000 个家庭 × 25 年
```

这个预注册涵盖了研究问题、条件、假设、指标、判定规则。它是**仿真开始前**就写好的——跑完之后,只有按这个协议判定的结果才算数。## 9.8　思考题

1. **选一个你关心的研究问题**(真实或假设),**判断它是否适合仿真**:是机制识别、反事实评估、长期动态、多变量交互、还是不可实验问题?
2. **为一个研究问题写预注册协议**:包括 1 个研究问题、2–3 个条件、3–5 条假设、每条假设的指标和 MDE。
3. **为限行令案例补充第 4–6 条假设**:除了 H1–H3,你还能想到哪些可被仿真验证的假设?
4. (进阶)**为你的研究估算样本量**:多少个条件 × 多少个种子 = 多少次仿真?总成本多少?

## 9.10 扩展:研究问题的精细化

把模糊的研究问题变成具体的仿真假设,需要经过精细化。本节展开讨论。

### 9.10.1　研究问题的层次

研究问题可以分四层:

- **现象层**:观察到"什么"
- **机制层**:"为什么"会这样
- **政策层**:应该"怎么做"
- **理论层**:这"意味着什么"

仿真最适合"机制层"和"政策层",不适合"现象层"和"理论层"。

### 9.10.2　问题分解

一个模糊的问题可以分解为多个具体的子问题:

```
[原始问题]为什么社会贫富差距持续扩大?

[分解后]
  - 问题 1:代际财富传递的机制是什么?
  - 问题 2:教育机会不平等如何影响财富积累?
  - 问题 3:政策干预(累进税、教育补贴)效果如何?
```

每一子问题可以做 1 个独立仿真。

### 9.10.3　假设的"形式化"

把假设写成"可证伪"的形式:

```
模糊:教育很重要
形式化:接受高等教育使 30 岁时收入提高 ≥ 30%(MDE 30%)
```

### 9.10.4　假设的反例

每个假设都应该能想到反例。写假设时,同时写"在什么条件下假设会失败":

```
H1: 限行减少私家车出行
反例 1:如果居民没有私家车,效应接近 0
反例 2:如果公共交通已饱和,居民不会转向公交
反例 3:如果弹性工作制普及,出行总量会下降而非出行方式转移
```

### 9.10.5　深度:研究问题的"五种坏问法"

研究问题常见的"坏问法":

**坏问法一:太宽**

- 例:"为什么社会不平等?"
- 问题:这能写出 1000 篇博士论文
- 修正:"在 X 城市 Y 时期,房价上涨 50% 的原因"

**坏问法二:太窄**

- 例:"居民 31 号买不买第 1 套房?"
- 问题:个体问题难以泛化
- 修正:"高房价区与低房价区居民的购房决策差异"

**坏问法三:无法证伪**

- 例:"社会仿真是否有用?"
- 问题:无法判断"没用"
- 修正:"在 X 任务中,LLM 仿真 vs 传统方法的预测准确度差异"

**坏问法四:无机制**

- 例:"为什么 X 现象出现?"
- 问题:无机制就是相关关系
- 修正:"X 现象由 Y 机制驱动的实证证据"

**坏问法五:无数据**

- 例:"理想社会的特征是什么?"
- 问题:无法实证
- 修正:"现有数据能验证理想社会的哪些特征"

学生做研究时,用这五条审视自己的研究问题。

## 9.11 扩展:预注册协议的细节

预注册协议的每个字段都有讲究。本节展开讨论。

### 9.11.1　指标的定义

指标必须明确"怎么算":

```
模糊指标:经济活跃度
明确指标:人均每月消费金额(元),基于 daily_consumption 加总,排除房租
```

### 9.11.2　条件的精确性

每个条件必须有明确的差异:

```
模糊:高补贴 vs 低补贴
精确:高补贴 = 公共交通票价 50% 折扣;低补贴 = 无补贴
```

### 9.11.3　方向的明确性

方向必须明确:

```
模糊:减少
明确:实施后均值 < 实施前均值的 90%
```

### 9.11.4　MDE 的合理性

MDE 必须基于真实数据估计:

```
方法:用预实验跑 30 天,看指标波动范围,MDE = 2 × 波动范围
```

### 9.11.5　判定规则的完整性

每条假设必须有明确的判定规则:

```
H1: 限行减少私家车出行 ≥ 15%
判定:实施后均值的 95% CI 上界 ≤ 实施前均值的 85% → supported
判定:实施后均值的 95% CI 下界 ≥ 实施前均值 → inconclusive
判定:实施后均值的 95% CI 上界 > 实施前均值 → contradicted
```

## 9.13 扩展:假设检验的统计学

仿真研究里的假设检验比传统统计复杂。

### 9.13.1　样本量的确定

仿真里的"样本量"是"种子数 × 条件数":

- 太少(<3):噪声主导,结论不稳
- 太多(>10):成本飙升
- 推荐:3 条件 × 5 种子 = 15 次仿真

### 9.13.2　效应量与 MDE

效应量 = 真实效应大小。MDE = 愿意接受的最小效应。两者关系:

- MDE < 效应量:能检测到
- MDE > 效应量:检测不到

经验法则:MDE = 效应量的 50%–80%。

### 9.13.3　多重比较校正

做多个假设检验时,需要校正显著性水平:

```
原始 α = 0.05
Bonferroni 校正:α' = 0.05 / k
其中 k = 假设数
```

### 9.13.4　事前 vs 事后分析

**事前分析**(a priori):在仿真前就确定,严格按计划执行。

**事后分析**(post hoc):跑完仿真后再选择,通常是"看到想要的结果"。

预注册只允许事前分析。事后分析只能作为"探索性发现",不能作为"假设检验"。

### 9.21 扩展:研究设计的常见错误

### 9.21.1　假设过于宏大

**错误**:假设太宽,难以验证

例如:"政策影响社会"——这是无法证伪的。

**修正**:拆解为多个具体的、可测量的假设。

### 9.21.2　指标定义不清

**错误**:指标定义模糊,事后可以调整

例如:"经济活跃度"——没有明确定义。

**修正**:每个指标必须有明确定义和计算公式。

### 9.21.3　样本量不足

**错误**:样本量太小,统计把握度不够

**修正**:功效分析 + 样本量计算。

### 9.21.4　多重比较未校正

**错误**:做多个假设检验,显著性通胀

**修正**:Bonferroni 校正、FDR 控制。

### 9.21.5　事后选择

**错误**:跑完仿真后选择"看起来好"的结果

**修正**:严格预注册,跑前固定。

### 9.21.6　忽视混杂变量

**错2.1　从问题到假设

把模糊问题变成具体假设的工作流:

1. **明确"是什么"**:研究的现象是什么?
2. **明确"为什么"**:可能的机制是什么?
3. **列出假设**:每个机制对应一个假设
4. **定义指标**:每个假设对应可测量的指标
5. **预注册**:固定假设、指标、判定规则

### 9.22.2　从假设到实验

把假设变成实验的工作流:

1. **设计条件**:每个条件对应一个世界
2. **估算样本量**:每个条件多少种子
3. **估算成本**:总调用次数 × 单价
4. **预实验**:小规模验证流程
5. **正式实验**:跑完整实验

### 9.22.3　从实验到结论

把实验结果变成结论的工作流:

1. **数据清洗**:去除异常
2. **指标计算**:每个假设的指标
3. **假设判定**:按预注册规则判定
4. **异质性分析**:按子组分层
5. **稳健性检验**:参数、种子、方法
6. **写结论**:严格按规则

### 9.22.4　从结论到论文

把结论变成论文的工作流:

1. **结构**:IMRaD
2. **图表**:标准可视化
3. **写作**:清晰、简洁
4. **预审稿**:自己模拟审稿
5. **外部审稿**:找同事审稿
6. **投稿**:选期刊,投出去
