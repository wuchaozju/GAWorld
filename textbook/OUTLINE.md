# 教材编写大纲（最终版）

> 与 `README.md` 配套：README 给目录全景，OUTLINE 给每章**详细写作要点**，是分章撰写的施工单。

## 全书体例约定

- **第二人称**：用"读者"而不是"我们"
- **每个技术章节**：原理 30% / 设计取舍 40% / 代码示例 30%
- **每个方法/案例章节**：研究问题 10% / 模型设计 25% / 运行命令 15% / 结果解读 30% / 教学讨论 20%
- **每个原理章节**：思想 70% / 历史与文献 20% / 习题与延伸阅读 10%
- **图表规范**：每章 2–4 张图（流程图/架构图/对比图），全部 Mermaid/PlantUML 源在 `assets/figures/`
- **代码示例**：每章 1–3 段可运行代码，文件名、依赖、命令行都明确
- **章末固定三件套**：本章小结（5 行内）/ 思考题（3–5 题）/ 延伸阅读（5–8 篇，含 arXiv 链接）

## 第一编　原理（3 章 ~3 万字）

### 第 1 章　社会科学研究的第三范式：从观察走向生成

**写作要点**

- 1.1 从"观察"到"生成"的范式光谱——把人类认识世界的方式分成 4 种：纯观察（民族志、历史档案）、干预观察（问卷、实验）、比较观察（跨国/跨期比较）、生成性研究（用人工社会重演机制）。这一节把仿真放在方法论光谱里,而不是另起炉灶。
- 1.2 社会科学的"实验稀缺性"——为什么双盲实验在社会学里几乎不可能（伦理、可重复、规模)。引出"如果不能做实验,能不能做可计算实验?"
- 1.3 解释性鸿沟：从"是什么"到"为什么"——以 Schelling 隔离模型为例,只用一句话规则能再现宏观隔离;反之从宏观数据看不到微观规则。这是社会仿真的合法性根源。
- 1.4 与思辨、与计量的边界——仿真不替代数学模型,但能处理非解析可解的非线性系统;不替代实证,但能突破"过去只有一次"的单例困境。
- 1.5 章节小结 + 思考题（5 题）+ 延伸阅读（Axelrod 1997, Epstein 2006, Lazer et al. 2009 Science, Watts 2014 Nature）

**教学钩子**：开篇用"古希腊 vs 中世纪欧洲 vs 玛雅"——为什么同样的技术基础产生不同结果?思辨够了,需要生成性研究。

### 第 2 章　社会仿真的认识论基础

**写作要点**

- 2.1 涌现、微观—宏观链接——4 个例子:鸟群、隔离、习俗演化、金融危机
- 2.2 Epstein "生成充分性" 15 问——精炼成 5 条核心检验(生成、机制、宏观涌现、可证伪、可复现)
- 2.3 可计算性边界——强计算 vs 弱计算;意义建构与主观体验仿不了
- 2.4 计算社会科学的合流——Lazer et al. (2009) 之后的社会科学
- 2.5 章节小结 + 思考题 + 延伸阅读

**教学钩子**：把"涌现"和"还原论"对立起来,讲清楚社会现象的"超加性"。

### 第 3 章　社会仿真简史与流派图谱

**写作要点**

- 3.1 1950s–1990s:Schelling(1971)、Axelrod(1984)、Epstein & Axtell(1996 Sugarscape)
- 3.2 2000s:Repast、NetLogo、ABM 进入 SSCI
- 3.3 2010s:大数据 + 行为经济学 + 计算社会科学
- 3.4 2020s:LLM 驱动的"会说话的社会"——Park et al. Generative Agents(2023)
- 3.5 五大流派:符号/行为/复杂系统/计算社会学/生成式——一张图谱
- 3.6 章节小结 + 思考题 + 延伸阅读

**教学钩子**:一张时间轴 + 一张流派图,让读者一眼看清自己属于哪一支。

## 第二编　技术（5 章 ~5.5 万字）

### 第 4 章　智能体：身份、状态与决策

**写作要点**

- 4.1 身份 schema 的最小完备集——姓名/年龄/性别/职业/收入/教育/家庭/住址/户籍/政治倾向/宗教/健康,11 项是经验值
- 4.2 九维状态空间(参考 GAWorld 实操)——生理(健康/疲劳)/心理(情绪/压力)/社会(归属/声誉)/经济(现金/存款)/认知(信息/技能)/关系(亲密度/义务)/能力(技能熟练度)/目标(优先级/计划)/偏好(口味/价值观)。每维给一个示例 agent。
- 4.3 行为策略四象限:规则/效用/启发式/LLM——什么时候用哪个,成本/可解释性/可信度如何取舍
- 4.4 记忆系统:短期(日内)/情景(事件级)/长期(总结)/关系(对人的印象)。这一节用 LLM 摘要 + 向量召回的工程实现串起来。
- 4.5 大五人格——OCEAN 在仿真里的工程化(参考 GAWorld 51 位采样),z 分标准化,与人设改写
- 4.6 代码示例:一个 200 行的最小智能体循环(MiniAgent 类)
- 4.7 小结 + 思考题 + 延伸阅读

**教学钩子**:开头用"小明的一天"——9 个维度怎么协同决定他下班是回家还是去同事饭局。

### 第 5 章　环境：城市、事件与时空

**写作要点**

- 5.1 环境的三个维度:物理空间(地点+距离+价格)、社会情境(同场所的人)、突发事件
- 5.2 城市地图:从规则网格(早期)到真实 OSM(现代),GAWorld 的 Nominatim + Overpass 流程
- 5.3 出行、通勤、场所效用——距离衰减 + 天气系数 + 高峰系数
- 5.4 环境事件分类:政策(限行/税)/自然(地震/洪水)/经济(通胀/失业)/技术(平台变化)
- 5.5 节律:工作日/周末/昼夜/季节
- 5.6 代码示例:一个城市 + 一个事件触发器
- 5.7 小结 + 思考题 + 延伸阅读

### 第 6 章　社会网络：关系、结构与传染

**写作要点**

- 6.1 关系的数据结构:强度(0-1)、亲密度(Dunbar 分层)、义务、可信度、上次接触
- 6.2 网络生成:小世界(Watts-Strogatz)、无标度(Barabási-Albert)、Dunbar 分层、地理就近、家庭优先
- 6.3 传染过程:信息扩散 vs 行为扩散 vs 情绪传染 vs 规范演化
- 6.4 动态网络:关系衰减、共演化、外遇加入、退出
- 6.5 幽灵节点:不在城里的家人、远方老同事
- 6.6 代码示例:用 NetworkX 生成 + 衰减 + 可视化
- 6.7 小结 + 思考题 + 延伸阅读

### 第 7 章　语言模型作为仿真引擎

**写作要点**

- 7.1 LLM 为什么改变社会仿真——文字推理 vs 数值反应 vs 行为涌现
- 7.2 提示词工程:四段式(身份/处境/选项/格式)——用 GAWorld 的真实 prompt 举例
- 7.3 可靠性——温度、结构化输出、重试、解析失败的处理
- 7.4 LLM-as-judge 与裁判偏置——交叉验证、规则回退、人类抽样
- 7.5 成本控制:路由(任务分流)、缓存、批处理、本地化
- 7.6 代码示例:一个最小 LLM 决策函数(无外部依赖)
- 7.7 小结 + 思考题 + 延伸阅读

### 第 8 章　运行系统：仿真循环、时钟与一致性

**写作要点**

- 8.1 时钟与步长:秒级(实时)/分钟级(日内)/日级(快进)/月级(中长期)/年级(世代研究)——GAWorld `--sim-years` 的工程实现

- 8.6 代码示例:一个 200 行的最小事件循环
- 8.7 小结 + 思考题 + 延伸阅读
