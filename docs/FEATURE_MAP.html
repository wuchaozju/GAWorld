GAWorld 功能地图

按"使用者 × 使用场景"组织的三级功能全景：5 个主轴（角色） → 每主轴 3–5 个能力子轴 → 共 79 个具体功能点。 每个功能点都在 docs/FEATURES.md 中有详细的作用与访问方法。

读图路径：先选你要扮演的角色（蓝/绿/红/紫/橙），沿子轴找到需要的能力，再点叶子查 FEATURES.md。 跨主轴共享的能力（如"本地 Dashboard"同时服务多类使用者）按其主要服务对象归位，并在 FEATURES.md 中可定位。

研究者5 子轴 · 15 功能



调研与提问4 项

    
  
  • 智能体采访 — 单 agent 深度访谈 interview --agent-id 31 --question "..."
    • 
  
  • 群体采访 — 一群受访者同一套题，可跨城市，连续追问 /site/dashboard/survey.html
    • 
  
  • RAG 外部知识注入 — 向某 agent 注入外部信息改变认知 rag-add --agent-id 31 --text ...
    • 
  
  • 从社交内容创建智能体 — 社媒页面 / 文本生成画像 create-agent-from-social --url ...
    • 






单点对照实验4 项

    
  
  • 事件对照实验 — 有/无事件两分支并行 compare-event --event-name ... --seed 42
    • 
  
  • 平行世界实验 — 最多 8 个世界共用居民/种子 parallel-worlds --spec worlds.json
    • 
  
  • 平行世界实验台 — 设计实验 + 分叉图 + 偏离曲线 /site/dashboard/worlds.html
    • 
  
  • 轨迹回放查看器 — 回放任意一次仿真运行 serve-viz --port 8000
    • 






预注册与长程仿真5 项

    
  
  • 运行仿真 — 让一批智能体按天循环生活 python generative_city_sim.py run
    • 
  
  • 长时段快进 — 每 agent 每步 1 次调用 --fast-forward
    • 
  
  • 大跨度模拟（月/年） — 一步 = 一月或一年 --sim-years 10 / --time-unit month
    • 
  
  • 时间单位：天/月/年 — 月年步长 + 日边界钩子按 ≤30 天区块补跑 CONFIG["long_run"]["unit"]
    • 
  
  • AI 社会科学家（阶段一） — 方案编译成预注册协议 + 平行世界跑 + 代码判定 POST /api/research/studies
    • 






研究设计4 项

    
  
  • 研究工作台 — 想法/论文 → 多种实验设计 → 预注册 /site/dashboard/research.html
    • 
  
  • 论文解读 — 从 .txt/.md/.pdf 解读出理论/方法/变量/发现/假设 POST /api/research/digest
    • 
  
  • 多设计与推荐 — 2–3 种不同思路的设计，城市/人口/时间/条件/事件/指标全标
    • 
  
  • 代码判定与报告 — supported/contradicted/inconclusive/unmeasured，附判定依据 GET /api/research/studies/<id>/report
    • 






副作用：仿真加速器3 项 · 跨主轴共用

    
  
  • 大跨度的社交影响 — 关系有走向，单步上限 0.25，正增量重置衰减计时
    • 
  
  • 大跨度的个体发展 — 技能长、人会变老，幂律曲线 + 年龄推进
    • 
  
  • 大跨度的动作与事件空间 — 动作空间按跨度换档，事件显形生成
    • 







世界构建者4 子轴 · 15 功能



城市与地图4 项

    
  
  • 城市地图生成 — 自然语言生成节点/道路/地铁 scripts/generate_citymap.py --description ...
    • 
  
  • 从地名新建城市 — 真实地名造出可仿真城市 python -m gaworld.city create "绍兴柯桥"
    • 
  
  • 城市面板 — 可视化建城/列表/批量加居民/删除 /site/dashboard/city.html
    • 
  
  • 切换当前城市 — 切换 map_path/csv_path/profile/环境事件 python -m gaworld.city use
    • 






人口构成4 项

    
  
  • 参数化人口合成 — 按人口学旋钮生成小镇 python -m gaworld.population --size 500
    • 
  
  • Population Studio — 5 步可视化人口设计 /site/dashboard/population.html
    • 
  
  • 往城市里加智能体 — 批量/单个/迁入 三条路径 python -m gaworld.city add-agents
    • 
  
  • 跨城市查看居民（只读） — 不切换就查看任意城市居民 GET /api/city/agents?city=
    • 






仿真环境与配置5 项

    
  
  • 本地 Dashboard — 配置编辑/运行控制/记忆查看 dashboard --port 8766
    • 
  
  • 外部系统观测台 — 观察/编辑货币/环境/对外服务 ~150 旋钮 /site/dashboard/external.html
    • 
  
  • 配置覆盖 — 不改源码即可覆盖基础配置 dashboard_config.json / GAWORLD_CONFIG_OVERRIDES
    • 
  
  • 可复现性 — 固定随机种子复现实验 --seed / CONFIG["random_seed"]
    • 
  
  • 重置 — 清除有状态产物，从 Day 1 重新开始 python generative_city_sim.py reset
    • 






大跨度与群体近似4 项

    
  
  • 群体（cohort）模拟 — 大规模人群低成本模拟 python -m gaworld.group --size 500 --days 7
    • 
  
  • 群体模式验证门 — L1–L4 量化 cohort 近似代价 python -m gaworld.group.validate
    • 
  
  • Cohort 遥测插件 — 在个体运行中发布群体划分与漂移，只观测不改行为
    • 
  
  • 日程网格对齐 — 把 agent 日程对齐固定时间网格，1440/step 恒定
    •

玩家4 子轴 · 12 功能



多人共玩3 项

    
  
  • 居民认领 — 在 open 世界认领居民、获得两分钟租约
    • 
  
  • 双向对话 — 干预队列走感知 + 动作通路
    • 
  
  • 会话与私信 — 逐条记录到 output/records/
    • 






互动游戏场8 项

    
  
  • 斗兽场 — 居民同台答题，按正确率+中位耗时排座次，淘汰补人
    • 
  
  • 说服游戏 — 有立场的问题 → 聊天 → 复问；裁判 LLM 判定核心结论是否变
    • 
  
  • 灾害模式 — ≤12 人过一场灾难，每幕一次调用，六类行动+恐慌+互助
    • 
  
  • 谣言扩散局 — 沿熟人图走，每人回一 JSON（信任度/动作/原话）
    • 
  
  • 双队竞赛 — 同任务两条相反的路子，评审拿到「方案一/方案二」洗队名
    • 
  
  • 公投局 — ≤14 人先私下表态，再公开表决，中间那屏带票数与最响原话
    • 
  
  • 猜人局 — 读档案猜两难里怎么选，「再问一次」量 persona 稳不稳
    • 
  
  • 谁是真人 — 真人和居民匿名同聊几轮，再互猜谁是真人；存档供 Bench Track D
    • 






协作与创作3 项
