协作规则

提出功能点时尽量写明背景和目标，便于其他参与者判断价值与工作量。认领后应填写自己的名字，并在推进时主动更新状态。

如果某个功能点遇到外部依赖、接口权限或设计不明确，可标记为“阻塞”，让其他人看到卡点在哪里。

所有成员访问同一个地址即可看到一致的功能列表；认领、状态更新和新增功能都会写入服务器。

当前页面由 GAWorld dashboard server 提供共享数据接口。推荐团队统一访问 /board。
