# GAWorld 平台功能介绍｜视频脚本与分镜

制作开始：2026-11-10 · 交付核对：2026-11-11 · 建议时长：180 秒 · 画幅：16:9（1920 × 1080）

## 创作设定

面向首次接触平台的研究者、教师、学生和开源开发者。以“从一个人，到整个世界”为主线：先建立居民与城市，再观察互动，最后形成可检查的模拟研究记录。主讲使用清晰、自然的普通话；旁白共约 670 个汉字，按每分钟 280–330 字配音约 2 分钟至 2 分半，其余时间留给界面阅读、操作展示与转场。时间码是剪辑目标，录音后可微调。

推荐风格：深绿底色、米白卡片、荧光黄强调，延续首页视觉。示意图解释关系与流程；实际录屏展示操作入口。图中不出现虚构的实验数值、真实姓名或没有来源的研究结论。

## 180 秒主片分镜

### 01｜从一个问题开始 · 00:00–00:12

**旁白**：如果同一座城市，换一条规则，居民的生活会怎样变化？GAWorld 是一个开源的生成式社会仿真平台，让我们从一个人出发，构建一个可以观察、互动和开展实验的世界。

**画面**：一个居民节点出现，关系连线逐步展开，拉远为城市，再落到功能全景。标题“从一个人，到整个世界”。

**素材**：`00-overview.png`；可补录首页首屏。**屏幕短句**：构建 · 运行 · 互动 · 研究 · 分析。

### 02｜构建城市与居民 · 00:12–00:35

**旁白**：从地名建立城市，配置环境与居民；也可以按人口结构合成一批样本。在智能体工作台，为居民编辑身份、职业、教育背景、人格和关系。记忆、目标与生活经历，让每个人拥有不同的处境，也为后续模拟提供起点。

**画面**：地图网格展开 → 居民卡片进入城市 → 依次高亮身份、人格、记忆、关系。录屏展示城市、人口与群体、Agent Studio。

**素材**：`01-build.png`。**屏幕短句**：城市环境 / 人口结构 / 居民档案。

**制作注**：地理路网获取失败有程序化地图兜底，不写“百分百复刻真实城市”；教育背景区分“已获学历”和“当前在读”。如补录真人蒸馏，只用有来源的材料，部署前需审阅。

### 03｜让生活持续发生 · 00:35–00:58

**旁白**：启动模拟后，居民感知环境、安排日程，工作、消费、交谈，并把经历带进下一次判断。家庭、社交、经济与外部事件相互作用。你可以观察一天里的细节，也可以按天、月或年快进，探索更长时间中的变化。

**画面**：感知 → 计划 → 行动 → 记忆 → 下一轮感知，依次点亮；旁边弹出工作、家庭、社交三个系统标签。录屏只使用已保存运行。

**素材**：`02-simulate.png`。**屏幕短句**：经历积累，反馈到下一次行动。

**制作注**：快进是粗粒度近似，不能展示为逐分钟仿真的无损加速；启用哪些子系统由配置决定。

### 04｜和居民互动 · 00:58–01:20

**旁白**：除了旁观，你还可以向居民提问。用群体采访，比较不同人对同一问题的回答；在游戏场，观察说服、谣言传播、公共议案和灾害应对。对话、选择与互动过程，会成为理解这群模拟居民的线索。

**画面**：一个问题发往三个居民，各自回复；切换说服、谣言、公投、灾害四张卡。录屏突出“提问—回答—汇总”，不使用虚构统计柱。

**素材**：`03-interact.png`。**屏幕短句**：群体采访 / 情境游戏 / 互动记录。

**制作注**：游戏机制不同，有模型裁判也有代码统计，不统一称为“客观评分”。

### 05｜把研究想法变成方案 · 01:20–01:52

**旁白**：研究工作台从一个想法，或一篇论文开始。先解读材料，再由研究者核对并选择设计，形成预注册协议。比如，比较同一批居民面对不同政策时的变化：设置基准和处理条件，检查预算与指标，批准运行，再查看代码计算的结果和模型解读。

**画面**：问题或论文 → 审阅 → 设计 → 协议 → 检查与批准 → 运行 → 判定与报告。展开两条平行世界线，标“基准”“处理”。

**素材**：`04-research.png`。**屏幕短句**：先明确问题，再运行实验。

**制作注**：示例问题为“公共交通补贴会怎样影响模拟居民的出行与生活？”仅展示设计，不预设效应方向、显著性或已经测得的结果。无法测量的指标不能假装进入判定。

### 06｜从不同角度检验 · 01:52–02:14

**旁白**：你也可以比较政策版本，让居民参与严肃游戏，或按文献中的条件开展社会调查与实验拟合度分析。需要检查结果是否稳定时，可以组织多模型、多城市和重复运行。保留材料、样本与运行记录，便于回到同一个问题继续检验。

**画面**：研究流程缩小，旁边依次出现政策比较、严肃游戏、文献拟合度、多模型与跨城重复四个标签。切换到实际研究工作台页签。

**素材**：复用 `04-research.png`，或实际页签录屏。**屏幕短句**：政策比较 / 文献对照 / 重复检验。

**制作注**：拟合度是对照指定研究的表现，不证明智能体等价于真人；政策推荐仅来自当前设定下的模拟评分。

### 07｜回到过程，查看证据 · 02:14–02:31

**旁白**：结果不只是一段总结。在回放与分析中，沿时间轴查看居民轨迹，结合状态、关系和运行记录，追踪变化怎样发生。对照不同世界，再导出报告，让讨论有可以回看的依据。

**画面**：回放时间轴由左向右移动 → 高亮一个居民 → 打开记录 → 并列展示两个世界 → 导出报告。

**素材**：`05-analyze.png`。**屏幕短句**：看轨迹 · 查记录 · 比较世界 · 导出报告。

### 08｜让课堂和团队参与 · 02:31–02:46

**旁白**：在多人部署中，每位用户拥有自己的世界；也可以进入开放世界，认领居民参与行动。教师组织情境，学生提出选择，让课堂讨论走进一个共同的模拟场景。

**画面**：个人世界卡片 → 开放世界中的三个参与者节点。录屏只使用测试账号，不展示邀请码、令牌或个人信息。

**素材**：`06-collaborate.png`。**屏幕短句**：个人世界 / 多人参与 / 课堂情境。

**制作注**：多用户需部署并启用账号系统；开放世界需相应权限与配置，并非默认启动即开放。

### 09｜边界与开源邀请 · 02:46–03:00

**旁白**：这里得到的是特定模型和规则下的模拟结果，仍需现实证据检验。GAWorld 的代码已经开源。欢迎查看项目、运行自己的世界，也把新的问题带进来。

**画面**：回到功能全景；停留片尾项目地址至少 5 秒。首页 GitHub 入口高亮后切至片尾卡。

**素材**：`00-overview.png` 或 `06-collaborate.png`。**屏幕短句**：模拟结果需要现实证据检验。

**片尾**：GAWorld · 从一个人，到整个世界。https://github.com/wuchaozju/GAWorld

## 配音与剪辑说明

- 独立旁白在 `voiceover.txt`，按九个镜头分段，可直接交给配音人员或语音工具。
- 单张 PNG 为 1920 × 1080；SVG 保留文字和矢量形状，可在设计软件中分层重绘或拆分动画。
- 图上的“功能示意”标识应保留，避免被当成产品实拍或研究结果。
- 建议：节点逐个出现、连线生长、卡片平移，每次动效突出一个关系；不要同时滚动多个面板。
- 配音优先，音乐音量保持较低；字幕在底部安全区内，单条尽量不超过两行。
- 本次交付脚本与示意素材，不含配音、动画、成片，也未自动替换首页已有视频。
