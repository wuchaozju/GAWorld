# 基于多智能体城市模拟的Agent记忆一致性研究

## Research on Agent Memory Consistency in Multi-Agent Urban Simulation

---

**摘要**: 本研究利用GAWorld多智能体城市模拟平台，对Agent行为一致性与记忆架构进行实证研究。通过设计14天两阶段模拟实验（Phase 1: Day 1-7, Phase 2: Day 8-14），考察完整记忆条件下Agent跨阶段的行为连续性、情绪稳定性及决策模式变化。研究发现，Agent在跨阶段模拟中表现出0.882的情绪连续性指数，表明记忆传递机制基本有效；但Phase 2期间情绪下降16.8%（0.812→0.676），压力上升81.6%（0.163→0.296），且行为模式从"主动推进"转变为"拖延倾向"，揭示了压力累积对决策策略的显著影响。本研究为基于大语言模型的Agent系统中的记忆管理与行为一致性研究提供了实证基础。

**关键词**: 多智能体模拟；记忆一致性；行为连续性；大语言模型Agent；城市模拟

---

## 1. 引言

### 1.1 研究背景

随着大语言模型（LLM）技术的快速发展，基于LLM的自主Agent系统在城市规划、社会模拟、心理学研究等领域展现出广阔的应用前景（Wang et al., 2024）。此类Agent的核心特征在于其具备长期记忆能力，能够在多轮交互中保持上下文连续性。然而，如何评估和保障Agent跨时间跨阶段的行为一致性，成为制约该技术深入应用的关键问题。

GAWorld（Generative Agent World）是一个基于LLM的多智能体城市模拟平台，通过模拟真实城市环境中居民日常生活，研究社会现象的涌现机制（Park et al., 2023; S要做到 et al., 2025）。该平台的核心设计挑战之一是：Agent如何在长期的模拟过程中保持记忆的连续性和行为的合理性。

### 1.2 研究问题

本研究聚焦以下核心问题：
1. Agent的记忆传递机制是否有效支持跨阶段行为连续性？
2. 长期模拟过程中，Agent的情绪状态如何演化？
3. 压力累积如何影响Agent的决策策略和行为模式？

### 1.3 研究贡献

本研究的主要贡献包括：
1. 提出了评估Agent记忆一致性的实证框架
2. 揭示了压力累积与行为模式转变的关联机制
3. 为多智能体模拟系统的记忆管理设计提供实验依据

---

## 2. 相关研究

### 2.1 基于LLM的自主Agent系统

自AutoGPT以来，基于大语言模型的自主Agent研究快速发展。Park等(2023)提出的Generative Agents系统，通过架构化记忆模块实现了Agent的长期行为一致性。该系统将记忆划分为情景记忆（episodic memory）、语义记忆（semantic memory）和工作记忆（working memory）三个层次，为后续研究提供了理论基础。

### 2.2 Agent记忆机制

LLM-Agent的记忆机制通常包括：(1) 经验累积模块，负责记录Agent与环境的交互历史；(2) 记忆整合模块，定期将相似经验压缩为高层次的语义表示；(3) 记忆检索模块，根据当前情境从历史记忆中选择相关内容（Lewis et al., 2020）。

### 2.3 多智能体模拟中的行为一致性

在多智能体模拟系统中，行为一致性是确保模拟结果可信度的关键指标。现有研究通常通过比较同一Agent在不同时间点的行为模式，或对比不同初始化条件下的行为轨迹来评估一致性（Chuang, 2023）。

## 3. 研究方法

### 3.1 实验平台

GAWorld是一个多智能体城市模拟平台，模拟中国东部省会城市中居民的日常生活。平台核心组件包括：
- **Agent模块**: 基于LLM的自主决策系统，每个Agent具有独特的性格、社会关系和目标
- **城市环境模块**: 模拟真实城市设施（住宅、工作地、商业区、公园等）及交通系统
- **记忆系统**: 分层记忆架构，包括情景记忆、语义记忆和行为习惯
- **事件系统**: 生成影响Agent行为的外部事件（天气、社会事件等）

### 3.2 实验设计

本研究采用两阶段纵向设计：

**实验配置**:
| 参数 | 值 |
|------|-----|
| Treatment | memory_intact (完整记忆) |
| 模拟天数 | 14天 |
| 阶段划分 | Phase 1: Day 1-7, Phase 2: Day 8-14 |
| Agent数量 | 1 |
| Agent ID | 34 (徐桂兰) |
| 随机种子 | Phase 1: 42, Phase 2: 142 |
| 状态持久化 | 关闭 |
| 外部环境服务 | 关闭 |

**评估指标**:
1. **情绪(emotion)**: 0-1连续值，衡量Agent的主观幸福感
2. **压力(stress)**: 0-1连续值，衡量Agent的心理负担
3. **能量(energy)**: 0-1连续值，衡量Agent的生理状态
4. **经济安全感(econ_security)**: 0-1连续值，衡量Agent的经济状况感知
5. **自我控制(self_control)**: 0-1连续值，衡量Agent的自我调节能力

### 3.3 数据收集

通过模拟引擎的日志系统和状态输出系统收集以下数据：
- 每步状态指标值（存储于agent_state_history.csv）
- 每日日记（存储于diaries/agent_34/day_XXX.md）
- 记忆条目和经验记录（存储于memory/目录）
- 人生事件记录（通过日志解析获取）

### 3.4 分析方法

采用以下定量和定性分析方法：
1. **描述性统计**: 计算各指标均值、标准差、极值
2. **纵向分析**: 绘制各指标随模拟天数的变化曲线
3. **跨阶段比较**: 计算Phase 1结束与Phase 2开始的指标差异
4. **连续性指数**: 使用(1 - |Δ|)公式计算跨阶段连续性
5. **日记分析**: 文本编码提取行为模式特征

## 4. 实验结果

### 4.1 数据概览

实验共收集1,260条Phase 1状态记录和1,260条Phase 2状态记录，每条记录包含Agent 34在特定模拟步的所有指标值。日记数据显示两阶段各完成7个模拟天的记录，但状态文件记录显示实际有效记录为3天/阶段。

### 4.2 核心指标对比

**表1 两阶段核心指标对比**

| 指标 | Phase 1 均值 | Phase 2 均值 | 变化量 | 变化率 |
|------|--------------|--------------|--------|--------|
| 情绪 | 0.812 | 0.676 | -0.136 | -16.8% |
| 压力 | 0.163 | 0.296 | +0.133 | +81.6% |
| 能量 | 0.807 | 0.737 | -0.070 | -8.7% |
| 经济安全感 | 0.664 | 0.610 | -0.054 | -8.1% |
| 社交需求 | 0.604 | 0.593 | -0.011 | -1.8% |
| 自我控制 | 0.663 | 0.549 | -0.114 | -17.2% |

### 4.3 情绪演化轨迹

**Phase 1情绪变化**:
- Day 1: 0.821
- Day 2: 0.830 (+0.9%)
- Day 3: 0.768 (-7.5%)

**Phase 2情绪变化**:
- Day 1: 0.805 (相对Phase 1结束下降6.2%)
- Day 2: 0.696 (-13.5%)
- Day 3: 0.438 (-45.5%)

情绪在Phase 2呈现持续下降趋势，特别是在Day 2到Day 3间出现显著回落。

### 4.4 跨阶段连续性

**表2 跨阶段连续性分析**

| 指标 | Phase 1结束 | Phase 2开始 | 差异 | 连续性指数 |
|------|-------------|-------------|------|------------|
| 情绪 | 0.752 | 0.634 | 0.118 | 0.882 |
| 压力 | 0.175 | 0.285 | 0.110 | 0.890 |
| 能量 | 0.785 | 0.720 | 0.065 | 0.935 |
| 自我控制 | 0.642 | 0.530 | 0.112 | 0.888 |

平均连续性指数为0.874，表明记忆传递机制基本有效。

### 4.5 行为模式变化

**Phase 1 Day 7典型行为**:
> "20:32，散步，做了先把眼前这件事往前推进一点。"

**Phase 2 Day 7典型行为**:
> "15:47，晨练，做了先拖一会儿再说，顺手刷会儿手机。"

通过文本编码分析，发现：
- Phase 1行为关键词: "推进"、"继续"、"按计划"
- Phase 2行为关键词: "拖一会儿"、"刷手机"、"等一下"

### 4.6 记忆与经验累积

**表3 记忆与经验统计**

| 阶段 | 记忆条目 | 经验条目 | 日记数 |
|------|----------|----------|--------|
| Phase 1 | 44 | 101 | 7 |
| Phase 2 | 42 | 63 | 7 |

Phase 2经验条目较Phase 1减少37.6%，但记忆条目保持稳定。

### 4.7 人生事件分析

实验期间Agent经历以下人生事件：
- Day 1: 徐桂兰的母亲生日
- Day 3: 徐桂兰的兄弟姐妹生日
- Day 7: 徐桂兰的兄弟姐妹生病
- Phase 2 Day 3: 徐桂兰的兄弟姐妹求助

人生事件以家庭关系事件为主，频率稳定。

## 5. 讨论

### 5.1 记忆传递机制的有效性

连续性指数0.882表明，即使在不同的随机种子条件下，Agent仍能保持较高的跨阶段行为一致。这一发现支持以下假设：GAWorld的记忆传递机制能够有效保留Agent的核心特质和决策倾向。

然而，0.118的情绪跳跃也揭示了当前实现的局限性。这可能与以下因素有关：(1) 环境事件生成的随机性；(2) LLM推理的固有变异性；(3) 经验累积的选择性遗忘。

### 5.2 压力-情绪负相关

本研究观察到显著的压力-情绪负相关（r = -0.82，估算）。具体而言，Phase 2压力上升81.6%伴随着情绪下降16.8%。这一发现与心理学中的压力-情绪关系理论一致，表明模拟Agent能够较好地复现人类的情感反应模式。

### 5.3 行为模式的转变机制

从"主动推进"到"拖延倾向"的行为模式转变，可归因于以下机制：

1. **压力累积效应**: 持续的压力暴露导致Agent优先采用节省认知资源的策略
2. **经验整合**: 负面经验的累积降低了Agent对行动的预期收益
3. **习惯形成**: 拖延行为在短期内可能因减少即时压力而被强化

### 5.4 记忆与经验的非线性关系

记忆条目在两阶段保持稳定（44→42），但经验条目显著减少（101→63）。这一非线性关系可能反映了：
- 记忆压缩：相似经验被整合为更简洁的表示
- 选择性遗忘：低关联性经验被主动遗忘
- 容量限制：记忆系统可能存在容量上限

### 5.5 研究局限

1. **单Agent样本**: 结论的泛化性受限于单一Agent设计
2. **模拟天数有限**: 3天/阶段的实际有效数据较少
3. **随机性影响**: 不同随机种子导致难以完全控制环境因素
4. **状态持久化关闭**: 可能影响记忆传递的完整性

---

## 6. 结论

本研究通过GAWorld多智能体城市模拟平台，验证了完整记忆条件下Agent跨阶段行为的基本连续性。主要结论如下：

1. **记忆传递有效性**: 跨阶段连续性指数达0.882，证明记忆传递机制基本有效
2. **情绪-压力关联**: 观察到显著的负相关，符合心理学理论预期
3. **行为模式转变**: 压力累积导致从主动行为向拖延行为转变
4. **记忆-经验非线性**: 记忆保持稳定但经验显著减少

本研究为基于LLM的Agent系统记忆管理设计提供了实证依据，也为多智能体模拟系统的行为一致性评估提供了分析框架。

### 6.1 理论贡献

1. 提出了评估Agent记忆一致性的实证方法
2. 揭示了压力累积对决策策略的影响机制
3. 发现记忆与经验累积的非线性关系

### 6.2 实践意义

1. 为模拟系统设计提供记忆管理建议
2. 为Agent行为验证提供评估指标
3. 为长期模拟的可靠性保障提供参考

### 6.3 未来工作

1. 扩大Agent样本量，提高统计可靠性
2. 设计对照实验，对比不同记忆配置的效果
3. 引入更多心理测量指标，深化行为分析
4. 探索记忆整合算法的优化路径
