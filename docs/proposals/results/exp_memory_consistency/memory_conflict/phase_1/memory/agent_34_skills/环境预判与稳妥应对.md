当遇到天气突变（如雨、降温、炎热、空气质量差）或其他环境变化时，先停下来判断当前状态和可能的代价。如果继续原计划会导致情绪波动或身体不适，立即调整为更省力的做法（如找地方避雨、降低运动强度、延后活动）。联系相关的人确认安排是否需要调整。宁可选择稳妥方案，也不要盲目坚持导致更大混乱。买菜等日常事务按清单处理，确保核心任务完成。
