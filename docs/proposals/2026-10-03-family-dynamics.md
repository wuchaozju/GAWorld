# 家庭：户结构的变化真正生效，以及让家人成为居民

日期：2026-10-03
状态：**已实施（2026-10-03）**——离婚选「两种都做，有人搬走」，家人成为居民选「这次就做」（默认关）。

## 一、核查出来的现状

路线图写的是「运行中结婚、离婚、生育还不会改变户结构」。代码里其实已经有 `family/lifecycle.py`（结婚 / 添丁 / 亲人离世）
和 `life.event.applied` 的接线，`FAMILY_DESIGN.md` §9 没跟着更新。但这条路**从来没有生效过**：

1. **插件调用转移函数时传了 `rng=self._rng`，而 `_rng` 从未赋值。** 每次都在事件总线里抛 `AttributeError`，被当成处理器
   失败吞掉——快进模式里模型选的「结婚」「添丁」、面板注入的同类事件，户结构一个都没变。测试只直接调了 `lifecycle` 的纯函数，没走插件。
2. **仿真内夫妻只改一方。** 两人各有一份户记录；就算转移生效，孩子也只会出现在事件主人的记录里。
3. **丧亲可能「杀死」仿真内的配偶。** 候选包括 75 岁以上的配偶，不分是不是仿真里的居民——一个还在城里走动的人会在记录里被标成去世。
4. **离婚不改户。** 面板的事件候选里有「离婚」「同居关系结束」，触发后只改情绪，配偶照样同住。
5. **子女和同住长辈始终是场外的人**：一行家庭简介、一项家务、一笔开销，从不上学、不出门、没有感受。

## 二、改法

### 2.1 转移真正生效（不加可比性版本）

- 每次事件用 `(family.seed, 居民, 天, 事件)` 播种的随机数，和事件到达顺序无关。`apply_transition` 先查资格。
- **全户同步**：一次添丁会写进同住的每位仿真内家人的记录——配偶记为子女，被升级的子女记为兄弟姐妹，长辈记为孙辈；
  亲人离世按成员键同步标记。新成员同时写进关系（以前转移后不写关系）。
- 丧亲只在场外的人里选。
- 默认运行不触发这些事件（家庭日常事件是 `family_*` 另一套；快进模式默认关），所以不加可比性版本。
  **但开过快进模式、或从面板注入过这些事件的旧 run，与之后不可比**——旧代码里它们没有效果。

### 2.2 离婚与分手（选项：两种都做，有人搬走）

- 资格：离婚要有同住配偶，分手要有同住伴侣。配偶变成「前任」、不再同住，关系降到前任的强度；婚姻状态改为离异（分手回到未婚）。
- **场外配偶**：对方离开；孩子按 55% 留下（与开局抽样离异者时用的抚养比例相同）；被升级为居民的孩子一律留下。
- **仿真内夫妻**：播种的硬币决定谁搬走，搬到离原住处最近的另一个住宅节点（地图上没有就仍登记在原地址，日志写明）。
  孩子和同住长辈留在原来的家；搬走的一方记录里其余人都改为不同住；户一分为二（家庭财务不再把两人当夫妻互相补贴）。
- 简化：同住长辈不论是谁的父母都跟留下的一方。

### 2.3 家人成为居民（选项：这次就做；`family.members_as_agents`，默认关）

- **谁**：开局前，同住的 6–17 岁子女，以及 60 岁以上的同住长辈（更年轻的同住父母往往还在工作，需要自己的收入，仍留场外）。
  上限 `max_new_agents`（默认 20）。仿真内夫妻共有的孩子只升级一次。
- **怎么成为居民**：在 `agents.built`（优先级 20，先于其它插件的播种）把他们追加进本次运行的居民列表——主循环之后对每个居民做的
  初始化（记忆、关系、日程、动作空间、社交网络）对他们照常进行。id 从 1,000,000 起按（户、成员键）的稳定顺序编号，同一种子同一批人。
- **画像**：孩子按年龄是小学 / 初中 / 高中生，长辈是退休在家；性格、日常、价值观是固定模板（(c) 类）；状态里家庭共有的
  （经济安全感、城市认同等）跟家长，其余取中性值。住在这户的家里；孩子白天的地点是离家最近的学校。
- **户记录**：家长记录里的成员从场外改成居民（键换成新 id）；新居民有自己的视角——孩子看到父亲 / 母亲 / 兄弟姐妹 / 祖辈，
  长辈看到儿子（儿媳）/ 孙辈。按 `assign` 的抽样方式，夫妻同住的长辈是男方的父母。家庭简介按这个视角写。
- **账本上仍是被抚养人**：不建账户、不找收入；这户照旧按原来的被抚养人开销付钱。否则一个九岁的孩子会落进非就业人群的低收入带，
  「写作业」就有工资。
- **不独自出行**；没有家务责任文本（那是大人的）；户的经济状态对情绪的影响不施加在他们身上。
- 不在运行中途升级：满 6 岁的孩子、新生儿仍留场外。

**实测**（模拟 LLM、真实主循环，居民 4 被指定有一个 9 岁的孩子）：孩子作为 1000000 号居民走完一天，有自己的感知 / 计划 / 反思调用，
家庭记录里是「和家人同住：母亲……、父亲……、祖母……」。

## 三、仍未做

- 运行中途的升级（孩子满 6 岁、长辈满 60 岁）与降级（孩子成年离家时被升级的孩子留在原处——成年离家只对场外子女生效）。
- 被升级的孩子没有同学关系；社交网络按职业和年龄分组，同龄孩子会自然连在一起。
- 家庭日常事件（孩子发烧……）仍只落到这户的成年居民身上，不落到被升级的孩子本人身上。
- 仿真内两位居民之间的结婚（目前结婚只会产生场外配偶）。
