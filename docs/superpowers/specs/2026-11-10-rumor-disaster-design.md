# 谣言与灾害模拟改进

用户已于 2026-11-10 确认完整方案。仅改游戏沙箱，不改常规仿真认知管线或城市居民数据。

- 谣言：相信程度、传播行为、动机分离；保存每次发言与传播内容，接收者只看到实际收到的转述。低相信程度仍可玩梗转发，不强制任何转发比例。熟人社会证明只统计相邻节点的上一轮状态。
- 灾害：新增保护家人、转移财产、等待官方通知；主行动与次要行动分开。五档恐慌是模型角色自报，并非经验证量表。
- 统计：总反应数为居民×阶段人次；行动、恐慌、互助各有有效分母。失败字段保持缺失，不填中性值；无有效数据时显示缺失。互助指对家庭之外他人的帮助，与保护家人分开。
- 情境：读取已有地域资料生成确定性分阶段情境，山区、沿海、水乡采用不同条件；缺资料明确回退通用情境。自定义剧本原文优先。
- 关系：优先读取人口种子中的明确关系；缺失时按同住址、职业、年龄生成标记为推断的联系，不以同姓证明亲属关系。上一阶段消息经边传播；停电断网限制远程渠道，保留可见的同住址接触。保存边、观察与信息事件，不把全体统计冒充每个人的邻居。
- 解析：严格 JSON 优先；有限容错支持单引号、尾逗号与 JSON 布尔字面量混用，禁止执行表达式。字段独立校验；原始文本放诊断信息，不在行动或原话里冒充居民反应。
- 页面与 Markdown 导出同步展示口径、数据质量、地域依据、关系来源及传播记录。保留旧结果兼容读法。
- 结果标记机制版本；不以离线测试宣称与真实人类等价，不自动运行付费实验。

验收：畸形输入恢复/拒绝，缺失与 false 正确处理；失败不污染统计；娱乐传播到下一跳；不同地域不同阶段；网络隔离与阶段同步；页面/导出口径一致；核心测试与目标 lint 检查。
