# 研究工作台：流程恢复与分层阅读

用户于 2026-11-06 确认「流程恢复 + 分层阅读」，授权直接实施。

## 已确认问题

- 生成方案与协议的轮询遇到一次断连便停止，后台工作可能仍在运行。
- fetch 没有超时；生成中的任务 id 未保存，刷新后丢失追踪。
- 生成/编译只有粗粒度消息；统计后仍等待可选的模型解读。
- 结果位于协议、日志之后，方案里的功能映射先于推荐实验设计，阅读主线被打断。

## 设计

保持现有研究方法、预算、实验隔离、用户/世界权限及已有记录。增加可恢复任务追踪：有界请求、退避重连、作用域内恢复、终态保留。生成与编译任务落盘，重启后明确标记中断，不自行重启模型调用。运行阶段已有统计时先保存可下载报告，并显示「统计已完成、解读中」。模型调用增加研究专用等待预算，不更改其他仿真的模型配置。

阅读入口增加由现有结构化数据生成的研究摘要和结果摘要：研究问题、实验比较、指标、运行规模；逐条假设的结论、依据及限制。技术记录折叠，完整原始表格保留；中英文、深色与窄屏可用。页面与 Markdown 导出采用相同摘要内容。不得将仿真结论写成真实组织或真实人群的事实。

## 验收

断连后恢复原任务；刷新不重复 POST；404/权限错误明确终止；旧响应不覆盖新任务；模型长等待可终止并保留已计算结果；已有研究及导出可读；研究相关测试及 core suite 通过，受控浏览器验证桌面/手机布局。

## 实施补充（2026-11-08）

提交标识在发出 POST 前保存，后端按用户/世界幂等预留；无本地持久存储时仍可通过内存标识恢复。模型等待采用有界 I/O worker 限制调用者总等待；无法取消已交给服务商的请求，但迟到结果不会保存。论文解读连同原材料可恢复，避免刷新后无法继续生成方案。
