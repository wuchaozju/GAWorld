# 回放与分析工作台

2026-10-26 用户已批准「地图／室内场景 + 居民详情 + 指标与事件 + 统一时间轴」方案，并授权实施。

## 工作流与布局

控制台只保留一个「回放与分析」入口。`#analytics` 为规范入口，`#simviz` 及旧独立回放页兼容并保留运行查询参数。共用页首、运行选择和三个视图：联动回放、专题分析、系统概览。复用现有世界选择器和权限接口。

联动回放上方选择、搜索和筛选运行；主体左侧显示城市地图或室内场景，右侧显示居民选择、活动、状态、感知、计划、行动结果和反思；下方展示可选指标的逐帧曲线和可跳转的事件列表；底部时间轴提供播放、暂停、前后帧、倍速、首末帧和时间选择。

选居民会同步地图突出显示、室内位置、详情和曲线；点击曲线和事件会定位对应帧。切换运行中立即清空旧画面及分析，过期请求不得覆盖新运行。播放到末帧停止，从末帧点击播放从头开始。刷新保留当前帧和居民（仍存在时）。

## 数据与边界

沿用 `/api/replay/runs` 和 `/api/analytics/runs`，以存储 id 合并权限过滤后的列表。仅当同一目录树、生成时间、帧数与结束状态均一致时合并当前文件和存档副本；保留别名以兼容旧深链接。运行中的来源标签不等于进程正在运行；未完成轨迹显示「未标记完成」。

同步曲线直接取 `trace.frames[*].agents[*].state`，按记录的 day/time 排列；不将只有 step 的状态 CSV 按比例硬对齐。缺值断线、不填零。展示真实时间范围与观测居民数；计划天数仅作为计划信息。专题分析沿用经济账本、关系快照、行为统计、事件和现有 HTML/JSON/CSV/Markdown 导出，并明确其整次运行或快照口径。存档缺少独立账本时不读当前运行的文件补齐。

## 工程与验收

无新增前端依赖或构建步骤。复用 CityMapView、IndoorView、analytics.js 和 analytics-export.js，新增独立的纯数据模块、工作台交互模块和样式。系统统计保留管理员权限限制。

测试时间对齐、缺值、事件去重、运行合并和别名、请求竞态、空轨迹、路由兼容和导出。浏览器检查两旧入口、运行切换、地图／室内、居民／曲线／事件联动、播放、主题、中英文和 390px；运行相关 pytest、Node 测试、核心套件、差异及 lint 检查。工作树已有修改保持原样，交付不自动提交。
