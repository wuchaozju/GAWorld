# 首页：现代社会实验室

## 第二轮：更大胆的交互叙事

用户进一步授权突破原有内容和板块，增加示意图与动画。沿用实验室主题，改为深森林绿全幅首屏、荧光青柠点缀和米白叙事段落，以「个体 → 关系 → 社会 → 反事实」组织内容。

- 首屏：大字号宣言与可切换城市/关系/分岔视角的动态城市画布；提供全局动画暂停。
- 个体章节：带人物、记忆、判断和行动的循环示意；切换不同情境说明认知过程，入口指向智能体工作台。
- 关系章节：大型分群关系网络，切换家庭、工作、社区查看不同连线；入口指向采访与游戏。
- 分岔章节：共享基线分为对照与干预两个世界；滑杆改变示意曲线间距。明确属于交互示意，曲线不代表研究结果，未调用模型、未启动研究。
- 功能索引：保留六个真实功能入口，以更紧凑的分栏索引呈现；资料和安装折叠整理，贡献者集中至页尾。
- 动效：城市居民沿路移动、消息沿关系流动、循环路径和曲线绘制、滚动进入。全局暂停控制 CSS/SVG/Canvas；系统减少动态效果与页面隐藏时停止持续绘制；基础内容不依赖动画才能理解。

新增浏览器回归检查全局暂停/继续、减少动态效果、关系视角和分岔滑杆、中英文及手机导航，保留之前的路由与资源检查。

### 本轮追加要求：功能更具体，研究更科学

用户指定「01 / 探索平台」应更形象具体、「02 / 从问题到证据」应增强科学性。最终将探索平台前移，六个入口各自配有独立矢量场景、输入到产物的路径和使用例子；人物认知与关系网络作为后续深入介绍。

研究部分采用六步流程：可检验假设 → 预注册设计 → 共同基线 → 配对运行与记录 → 效应与区间 → 稳健性与边界。加入明确标注的政策信息示例、A/B 条件、相同题目与量表、居民配对差值公式、区间跨零示意；方法说明对应 `gaworld/parallel/causal.py` 和 `gaworld/research/evaluate.py` 已实现的 Bootstrap、符号翻转、BH、前期平衡/DiD、安慰剂和跨种子复核。居民互动不等于独立重复，跨种子以整次仿真为重复单位。全部示意不提供虚构结果。

用户已选择方案 A：浅色底、深色大标题、森林绿主视觉和少量橙色强调。

## 页面与交互

首页服务于初次访问者和已有用户：首屏说明平台用途，并提供进入控制台、开始研究的真实入口。主标题为「让一个社会，在你眼前发生。」；副标题说明居民、城市、互动与可追溯对照实验。

右侧展示带有城市、关系、平行世界三个视角的矢量示意。视角按钮支持键盘切换，并提供对应功能入口；所有示意明确标注为机制示意，不展示虚构实验结果或在线人数。

首屏下方依次为六个功能入口、从居民到实验的研究流程、评测与文档、安装命令、贡献者与页脚。文档入口与功能入口分别标清。保留安装命令、Word 手册、评测链接和全部贡献者。

## 实现边界

沿用原生 HTML、CSS、JavaScript，不增加前端构建依赖。正式首页是 `site/index.html`；共享已跟踪的 `site/home/style.css` 与 `site/home/app.js`，同步 `site/home/index.html`，避免依赖被忽略的根目录样式脚本。使用文字标识和原生矢量示意；不依赖受保护的品牌图片。

接入已有 `site/theme.js`，保持明暗主题和持久化行为。保留中英文切换，首屏内容在禁用 JavaScript 时仍可阅读和跳转。手机导航具有展开状态与键盘操作；遵循减少动画偏好。
