# 研究批次与比较（已确认设计）

2026-10-17，用户确认统一批次方案，并明确 Python 导出调用研究者本机 GAWorld API。

同一份预注册协议按模型 × 城市 × 重复运行展开。每个单元是独立的子研究，包含完整的对照、处理、可选安慰剂及问卷；输入文件冻结并计算 SHA-256，居民 ID 按城市解释。不同种子与固定种子重复分别标记。批次保留所有任务及失败，比较以运行而非居民为重复单位，展示效应均值、标准差、95% t 区间、方向一致性和有效运行数。实际模型、执行模式、可比性版本或样本不符的结果不能混合。

批次复用现有研究运行器、限流、日志、遥测和暂停/继续/停止。模型与城市配置按任务隔离，不修改当前城市和全局模型。启动前检查全部任务与总预算；生成/下载批次不触发模型调用。批次及子研究按用户/世界隔离。

界面在研究卡片旁提供批次配置、历史、任务表及比较表；可选择比较结果、查看子研究日志、下载 JSON/Markdown 报告及 Python ZIP。导出包含固定协议、实验矩阵、输入快照、运行脚本和说明，不包含密钥。脚本向本机 API 导入、检查、启动并下载结果；本机缺模型或版本不匹配时明确报告，不能静默换模型。

验收：矩阵展开与独立产物；固定/不同种子；多城市同 ID 无串用；缺失与失败分母；统计与比较边界；跨用户/世界不可见；暂停/停止竞态；导出无密钥并可通过本机 HTTP API 往返运行；现有研究回归、核心套件、OpenAPI 和前端检查通过。真实付费实验不属于本次工程验证。
