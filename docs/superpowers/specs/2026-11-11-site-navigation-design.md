# 网站布局与导航优化方案

状态：用户于 2026-11-13 确认继续，已按推荐范围完成。验证结果见 `docs/reports/2026-11-13-site-navigation.md`。

## 范围与依据

本轮建议覆盖两个首页入口（`site/index.html`、`site/home/index.html`）及控制台外壳（`site/console/`），沿用现有绿色品牌、共享主题和功能分组。

当前源码中的布局问题：

- 首页主导航之外还有主题、语言、GitHub、社区、登录、注册和进入实验室等操作；900px 以下隐藏顶栏的实验室入口，而其他操作继续占据顶栏。
- 控制台顶栏集中放置面包屑、世界切换、世界管理、账号、退出、独立窗口及外观设置；共享的 `site/city-lab.css` 在860px以下将其排成多行并隐藏面包屑。
- 控制台侧栏已有分组和折叠功能，但中文界面每项都重复展示英文副标题，占用纵向空间。

以上是源码检查结果；具体溢出尺寸和视觉表现需在实现前后用浏览器对照验证。

## 方案选择

1. **推荐：入口与外壳整体优化。** 首页导航分清主次，控制台减少工具栏占用，侧栏提高可扫描性，统一适配手机和平板。覆盖日常进入网站和使用工具的完整路径。
2. **仅优化控制台。** 改动范围较小，但首页导航密度问题保留。
3. **全站逐页重新设计。** 覆盖更广，但涉及大量独立业务页面，超出本轮建议范围。

## 推荐设计

### 首页

- 桌面顶栏分成品牌、主导航、主要操作三个区域。主导航使用“了解 GAWorld / 探索功能 / 研究社区 / 文档”，右侧突出“进入实验室”。
- 主题、语言、GitHub及注册收进可点击的辅助菜单；登录保持可见。功能仍完整可达。
- 窄屏保留品牌、进入实验室和菜单按钮。展开菜单统一承载导航和辅助操作，支持 Escape 关闭及焦点回归。
- 梳理首屏、功能入口和后续章节的容器宽度与间距；功能入口在桌面、平板和手机分级排列。保留现有展示内容和视频。
- 两份首页同步调整，锚点定位预留固定顶栏高度。

### 控制台

- 主顶栏突出当前页面及世界上下文。账号和外观等辅助动作放入工具菜单，世界管理仍可直接到达。
- 手机顶栏显示当前页面名称；世界切换采用紧凑的独立上下文行，避免账号及设置连续堆高。
- 侧栏沿用“构建 / 运行 / 实验 / 分析”等分组，按当前语言显示名称，去掉重复英文副标题；强化选中项与分组间隔。
- 保留桌面图标折叠模式及偏好记忆，手机使用抽屉。打开时移动焦点，关闭后返回触发按钮，背景内容不可误操作。
- 整理外壳样式与共享样式之间的重复覆盖，维持内容区可用高度及独立滚动。

### 兼容与异常

- 使用已有主题 token；新增表面颜色同时提供深浅色值。
- 新文案提供中英文，遵循现有首页及控制台各自的翻译机制。
- 保持 hash 路由、旧链接重定向、iframe 缓存、账号权限和世界切换行为。
- 辅助菜单仅呈现当前用户可用操作；单用户模式不出现空账号或世界容器。
- 不依赖悬停打开菜单；触摸和键盘均可操作。菜单有可访问名称、展开状态和清晰的焦点样式。

## 验证与验收

- 浏览器检查 1440、1024、768、390 和 320px 宽度，中英文及深浅色均无外壳横向溢出或操作遮挡。
- 检查长世界名与长账号名、单用户和多用户状态，以及授权导航显隐。
- 检查菜单点击、Escape、焦点返回、侧栏折叠记忆、键盘导航、地址深链、前进后退和独立窗口链接。
- 检查桌面与手机抽屉切换后不会遗留遮罩或焦点锁定。
- 运行已有首页、导航、主题和相关前端回归测试；为新增交互补充行为测试。
- 交付前后截图和简短验证记录；本轮不触发付费模型调用或仿真运行。
