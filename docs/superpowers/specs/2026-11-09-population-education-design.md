# 人口教育背景与成年在校生

## 数据契约

`education` 表示已获得的最高学历，`student_status` 表示当前在读阶段。两者分开保存在人口 CSV 和档案，未知不能根据年龄猜成大学生。大学生包含大专与本科，研究生包含硕士与博士。旧档案只读取明确写出的教育和在读信息。

## 生成与兼容

成年在校生比例以 18 岁以上人口为分母；从年龄、已获学历、非劳动人口身份都合适的人中按独立种子抽样，保留就业率与学历拟合结果。不能达到目标时展示实际值和容量限制。大学城采用更高比例。学生档案使用学习日常。既有人口不自动重生成，也不将青年家庭照料者改标成学生。

## 操作入口

Agent Studio 身份页编辑学历、在读阶段与职业，保存后 CSV、档案及读回一致。居民选择器按教育、在读、年龄、性别、职业组合筛选，并展示人数；随机选择使用筛选后的池。实验复现把相同条件写入规格、抽样和运行记录，缺值不匹配受限条件，样本不足明确显示。

在 Agent Studio 提供成年学生追加入口：配置阶段、人数与种子，先预览再追加到当前世界。预览不写文件，追加保留旧居民与实验数据；人口已变化则重新预览，避免重复提交。

## 验证

测试固定种子的再现性、年龄/学历/在读一致性、目标缺口、旧数据未知值、CSV/档案回读、筛选排除同龄非学生、追加预览与防重复、活动世界路径隔离及前端筛选。无真实模型调用。
