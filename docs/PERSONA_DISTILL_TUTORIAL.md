## 0. 它做什么，不做什么

工作台原本的「＋ 新建」是**凭空造人**：你填姓名、年龄、九个状态变量，系统生成一位虚构居民。

真人蒸馏回答的是另一个问题：**「把某个真实存在的人，做成这个世界里的一位居民」**。

| | ＋ 新建 | ＋ 从真人蒸馏 |
|---|---|---|
| 输入 | 你填的每一个字段 | 一个姓名，或一个网址 |
| 来源 | 无 | 公开检索结果，逐条记 URL |
| 产出 | 身份 + 9 个状态变量 | 身份 + 状态 + 大五人格 + **思维框架** |
| 思维框架 | 无 | 心智模型 / 决策启发式 / 表达 DNA / 反模式 / 画像边界 |
| 落盘 | 直接写种子文件 | 先写 `output/personas/`，**人工复核后**才写世界 |

**捕捉的是 HOW they think，不是 WHAT they said。** 这条来自 `nuwa`：
一份好的人物画像是一套可运行的认知框架，不是语录合集。

**做不到的事写在画像里**。每份画像都带一节「画像边界」，说明它基于多少条材料、
截止到哪天、公开表达与真实想法可能有多大差距。这一节不是模型自愿写的——
有两条限制由代码强制附加，模型删不掉。

## 1. 三分钟跑通

1. 起面板：

```bash
python -m gaworld.apps.dashboard_server --port 8766
```

2. 打开 `http://127.0.0.1:8766/site/dashboard/studio.html`，点顶栏 **＋ 从真人蒸馏**。
3. 输入一个姓名（如 `张三`）或一个网址（如某人的主页 / 访谈页），按 **开始蒸馏**。
4. 等 30-90 秒。进度条会依次走过：检索四个方向 → 阅读正文 → 建立档案 → 提炼思维框架。
5. 复核结果：左侧是画像，右上角是**证据强度**，最底下是**资料来源**（可点开原页）。
6. 选一条路落地：
   - **填入表单** —— 把结果灌进七步表单，逐步改完再按「保存」；
   - **直接部署为居民** —— 跳过表单，立刻写入当前城市。

## 2. 两种输入：姓名与网址

**姓名模式**：四条检索式直接用姓名拼出来（见下一节）。适合有一定公开报道的人。

**网址模式**：先抓这一页的正文，从 `<title>` 推断姓名，再拿这个姓名去跑同样的四条检索式。
所以给一个人的主页 / 访谈页 / 演讲稿页，比只给名字得到的材料更扎实——
那一页是一手材料，检索结果是它的外围。

同名的人怎么办：如果材料明显讲的是另一个人，模型会把 `off_topic` 置位，
面板直接报「检索到的材料与「X」无关」，而不是给你一份混了两个人的画像。
这时改用更具体的姓名（加单位、职务）或直接给网址。

## 3. 检索：四个方向 + 读正文

四条检索式，一个方向一条（`gaworld/persona/research.py:SEARCH_FACETS`）：

| 方向 | 检索式 | 为什么 |
|---|---|---|
| 履历 | `{name} 简历 经历 背景` | 先知道他是谁，才谈得上他怎么想 |
| 观点 | `{name} 观点 主张 访谈` | 心智模型的主要来源 |
| 决策 | `{name} 决策 争议 事件` | 真实行为 vs 声称，两者不一致时保留不一致 |
| 近况 | `{name} 最新 近况` | 防止画像停在五年前 |

四条是刻意的上限——每条都是一次真实检索，整个过程本来就是 30-90 秒的交互式操作。

**摘要不够，要读正文。** 搜索摘要是引擎按查询词截的 ~120 字，够判断「这页存在」，
远不够判断「这个人怎么想」。所以命中的前几条会被完整抓取正文，走
`gaworld/io/http_guard.py` 的限流与失败缓存——和新闻管线共用同一套护栏。

搜索失败、页面抓不到，都只记日志跳过：半份材料还能蒸馏出一份**低证据**画像并如实标注，
抛异常则会连已经拿到的材料一起丢掉。

## 4. 蒸馏：两次模型调用

**第一次**建档案：姓名、性别、年龄、户籍、常住、职业、教育收入、日常、社交、价值观。
这些正是七步表单里已有的字段。

**第二次**提炼思维框架：

- **心智模型**（3-7 个）：此人在**两个以上不同话题**里反复使用的同一套看法。
  只在一个场合出现过的降级成决策启发式，材料撑不起来的直接不写。
- **决策启发式**：写成「如果 X，则 Y」，带具体事例。
- **表达 DNA**：句式、用词、节奏、幽默方式、确定性表达、口头禅。
- **价值排序 / 反模式 / 内在张力 / 智识谱系**。
- **仿真种子**：9 个 `[0,1]` 状态变量 + 5 个大五人格 z 分数。

为什么分两次：一个要求模型一次吐 15 个字段（含 14 个数字）的提示词，
模型会开始「概括」而不是「回答」。分开之后每个提示词都小到能被认真对待，
面板也能显示两个真实阶段而不是一条假进度条。

**两个提示词都写死了同一条规则**：只能用检索到的材料，没提到的字段留空。
模型自己报告留空了哪些字段（`unknown_fields`），面板把它们显示成「资料不足」，
而不是一个看不出区别的空白。所有数字都在代码里做二次钳制：
状态变量夹到 `[0,1]`，人格分数夹到 `±2.5`——模型说 9.0，落盘就是 2.5。

## 5. 读结果：证据强度与画像边界

面板把出处放在结论**旁边**，不折叠：

- **证据充分 / 一般 / 不足**：按读到的**全文篇数**判定（≥3 / ≥1 / 0）。
- **材料 N · 全文 M**：一眼看出这份画像的底子有多厚。
- **资料来源**：每条都是可点的原链接，标注「全文」还是「摘要」。
- **画像边界**：模型写的限制，加上两条代码强制附加的——材料条数与信息截止日；
  证据不足时再加一条「本画像应当作草稿，落地前请人工复核」。

一份看起来笃定的画像可能只来自两条搜索摘要。这件事必须一眼可见，
否则三个模拟月之后没人分得清哪些是事实、哪些是模型补的。

## 6. 落地：填入表单 vs 直接部署

两条路写进去的东西**完全一样**，区别只是中间过不过一遍表单：

| | 写入位置 |
|---|---|
| 身份 + 9 个状态变量 | 当前城市的 state CSV（`data/cities/<slug>/agents.csv`） |
| 档案 + **思维框架** | profiles MD 的对应 Profile 块 |
| 大五人格 | `data/agents_big5.csv`，`source=persona_distilled` |

思维框架写进 **profile**，不是只留在档案里——profile 才是仿真真正读进提示词的东西。
一个只存在 `output/personas/` 里的心智模型，对居民的行为没有任何影响，
而那正是蒸馏它的全部意义。

大五人格种子文件缺失时（该插件是可选的），部署照常完成，返回值里
`big5_written: false`，面板会明说「未写入大五人格」。

## 7. 导出为 Skill

**导出为 Skill** 把这份画像写成一个 `nuwa` 形状的 `SKILL.md`，
复制到 `~/.claude/skills/<slug>-perspective/SKILL.md`，此后可以在 GAWorld 之外当思维顾问用。

章节顺序与 `nuwa` 产出的一致：心智模型 / 决策启发式 / 表达 DNA / 反模式 / 诚实边界 / 资料来源。

这一步**刻意与蒸馏分开**：蒸馏只写仓库内的 `output/`，导出会写进你的 home 目录，
影响的是你在**所有项目**里加载的东西。已存在时不会静默覆盖，面板会问一次。

## 8. HTTP 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/persona/distill` | `{subject}` → `{job_id}`，202 |
| GET | `/api/persona/jobs/<job_id>` | 进度、状态、结果 |
| GET | `/api/persona/list` | 已蒸馏画像列表 |
| GET | `/api/persona/detail/<slug>` | 画像 + 渲染好的 profile 块 + SKILL.md |
| POST | `/api/persona/deploy` | `{slug, identity?, state?}` → 创建居民 |
| POST | `/api/persona/install-skill` | `{slug, overwrite?}` → 装到 `~/.claude/skills/` |
| POST | `/api/persona/delete` | `{slug}` → 删除画像与调研素材 |

蒸馏是后台任务，一次只跑一个：两个并发蒸馏会把同一批搜索站点的请求速率翻倍，
而那正是 `io/http_guard.py` 要防的事。

## 9. 落盘位置

```
output/personas/<slug>/
├── persona.json    结构化画像（面板重新打开时读它）
├── research.md     原始素材，逐条带 URL
└── SKILL.md        nuwa 形状的思维框架
```

`research.md` 一定要留：这是一份关于真人的断言，
当有人问「risk_preference 0.8 是哪来的」，答案必须是一个 URL，而不是模型的回忆。

环境变量 `GAWORLD_PERSONA_DIR` 可以改档案目录，`GAWORLD_SKILLS_DIR` 可以改 Skill 安装目录（测试用）。

## 10. 边界与伦理

- **只用公开资料**。这条管线只会读检索引擎返回的公开网页，不碰任何需要登录的来源。
- **公开表达 ≠ 真实想法**。每份画像都写着这句话，因为它总是成立。
- **落地前人工复核**。默认路径是「填入表单 → 逐步复核 → 保存」，
  「直接部署」是快捷方式，不是默认。
- **同名与张冠李戴**是这类系统最常见的错误。模型判断材料跑题时会直接拒绝出画像。
- 仿真里的这位居民**是一个模型**，不是那个人。用它做研究时，结论应当归于模型，
  而不是归于被蒸馏的真人。
