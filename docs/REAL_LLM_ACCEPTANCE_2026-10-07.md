## 未解决问题

1. **地图响应式尺寸。** 从 1440 像素宽缩为 390 像素宽后，地图容器仍为 1100 像素宽，人物可能被裁掉。
   `site/dashboard/citymap-view.js` 的 `_buildHost()` 复制计算后的固定宽高，`site/simviz/replay.js` 的缩放处理仍引用被替换的旧 canvas。
2. **地图异步加载稳定性。** 轨迹和人物侧栏可用时，地图仍可能停在默认世界视角，30 秒内没有人物图层；桌面与手机均观察到。
   后续一次重试显示了 56 个节点和人物，但底图尚未完全就绪。应检查图层重建时序和外部底图加载，不能只根据 JSON 200 或画布有颜色判断通过。
3. **天气规则错误。** `gaworld.behavior.dynamic._classify_event_type` 将 `natural/legacy` 的“清晨有大雾，能见度低”返回为 `('weather', 'rain')`，从而触发“找地方避雨”。
   已在部署环境独立复现；需要区分 fog、未知天气及 rain，并补规则和行为链路测试。
4. **计划时间不一致。** 06:00 的计划写“傍晚独自散步”，12:00 的事件包含“清晨大雾”。
   时间约束及事件有效期需要专项验证；粗时间步和提示词约束可能共同影响，不能把现象全部归因于模型。

上述问题本轮没有修改或发布修复。下一轮先修已定位问题、补回归测试，再验证平台按钮启动路径及更细时间步的小规模多智能体实验。
