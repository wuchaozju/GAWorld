# 组织智能重设计：实施与验证记录

日期：2026-10-26。对应用户确认的六步设计：`docs/superpowers/specs/2026-10-26-organization-intelligence-redesign.md`。

## 已实现的流程

组织材料上传/粘贴 → 可追溯、可编辑的组织规则 → 基线选择 → 内置/导入 benchmark → 保存与启动配对实验 → 结果和报告 → 保存组织方式 → 合作任务实际使用同一规则版本。

共享执行器在 `gaworld/collaboration/organization_engine.py`，负责接收人过滤、上一轮消息边界、审阅/修订、投票或汇总、资源限制与调用重放。研究逻辑位于 `gaworld/research/organization_intelligence/comparison/`，与原 OI-1、OI-2 独立。

新接口通过 delegate 路由接入，覆盖 OpenAPI、账号写权限和模型额度。研究、方法库及合作服务按用户/世界隔离。组织任务成果通过带权限校验的 API 下载，检查登记的文件名与实际路径，拒绝路径穿越和越界符号链接。

协议保存成员/题库/组织版本、模型指纹、代码指纹和分析规则。正式调用只在点击“开始实验”后发生。失败尝试也计量；完成的响应可重放。每个实验单元的原始调用单独存文件，进度记录只保存摘要，避免每次请求重写整项研究的全部提示词。

## 浏览器验收

使用隔离的 localhost 受控模型服务完成以下操作；没有调用外部模型：

- 直接输入组织描述、上传 TXT、上传有文字层的 PDF，确认提取结果。
- 分析规则、核对来源、采用规则、选择随机网络和问题类型。
- 导入真实 CSV 文件，检查字段与预览。
- 先保存设置，再显式启动；查看完成状态、成绩、成本和“尚无充分证据”的小样本结论。
- 加载历史研究，确认模型、角色、审阅、重复次数与选定成员正确还原。
- 保存规则到合作任务，选择匹配的三位成员，运行并实际点击下载 `final.md`；受保护下载 HTTP 200。
- 检查深色、浅色、英文，以及同源 iframe 内 390 像素的实际页面布局。

最终受控运行：2 道题 × 1 次重复 × 2 组，**4/4 单元完成，48 次模拟模型调用**；原始证据分成 4 个单元文件，进度文件为 6,148 字节。组织保存后，合作会话完成，规则内容和哈希与研究候选组完全一致。

本地产物目录：`output/research/organization_intelligence_redesign_acceptance/`。

- `final/acceptance-manifest.json`：研究、组织和合作会话的对应关系与规则哈希。
- `final/report.md`：程序生成的受控结果报告。
- `results-final-zh.png`：最终代码的中文结果界面。
- `mobile-light-en.png`：390 像素浅色英文页面。
- `source.pdf`、`source.txt`、`benchmark.csv`：上传和导入用的生成夹具。

验收使用固定回答验证程序行为，**不是已完成的真实模型研究，也不能据此判断任何现实组织的效能**。

## 使用入口与首版边界

正常模型配置的本地预览：`http://127.0.0.1:8796/site/dashboard/research.html?tab=organization-intelligence`。仅加载页面和模型列表，不自动开始真实实验。原来已运行的其他端口服务未被停止；如继续使用旧进程，需要重启它以载入新后端。

使用说明和 benchmark 数据格式见 `docs/ORGANIZATION_INTELLIGENCE_TUTORIAL.md`。

首版支持有限协作原语及逐题状态重置。跨题学习、成员更替和规则自我演化仍需要独立协议。token/金额未知时不估造；相同调用与字符上限不等于相同 token 成本。30 道独立题是最低报告门槛，不是功效保证；换模型、任务或人数不继承原实验的优势结论。
