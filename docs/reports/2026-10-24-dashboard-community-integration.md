# Dashboard 多用户与社区集成验证

日期：2026-10-24。

## 结果

个人空间与社区功能已接入现有 `/console` Dashboard 的侧栏。研究与仿真继续使用原工作台；总览、个人研究/世界、发布、收藏、消息、账号与社区讨论作为控制台视图打开。内嵌页面不显示独立页头/侧栏，并使用原 Dashboard 主题与字体。账号登录默认进入总览；游客公共分享链接仍可独立阅读。

旧 `/workspace?view=…` 和静态 workspace 入口转到对应控制台 hash。成果详情、版本、评论筛选、个人主页、研究方案及研究记录的深链接保留；浏览器返回与侧栏返回列表可更新同一视图。管理员/版主的导航按权限显示，操作令牌管理员不默认进入需要真实账号的私人总览。

跨世界打开研究或选择发布来源会刷新整个控制台，使世界选择器与所有面板一致。来源切换保留 publication/draft 目标及摘要、方法、局限、引用、标签、许可、附件和复选状态；标题与正文按新来源填写。临时编辑数据使用当前标签页 sessionStorage，恢复后清除。新加载的私人页与控制台首次读取的世界绑定，跨标签页 Cookie 漂移时显示刷新提示，不自动改绑。
