# 首页介绍视频接入

两个首页 `site/index.html`、`site/home/index.html` 在首屏下方加入视频区块，首屏次要按钮直达 `#intro-video`。使用 2026-10-22 的背景音乐版本，179.433 秒，内嵌中文字幕。视频与封面放入公开的 `site/home/media/`，不依赖本地 output 目录；Git 忽略规则已允许这两个资源随项目交付。

播放器使用原生 controls、playsinline 和 preload=none，不自动播放。初次打开页面未请求 MP4；点击后成功播放。复用现有语言切换与主题配色，新增样式在 390px、320px 无横向溢出。支持下载视频。

本地 Dashboard 原先的静态服务忽略 Range，浏览器无法拖动进度。`gaworld/apps/public_media.py` 为该视频的既有静态地址提供 GET/HEAD 和字节范围读取，返回 200/206/416，并保留现有访问检查。其他静态资源继续交给原处理器。已在新启动的 8798 测试实例验证 206、完整时长及跳到第 90 秒后的继续播放；原 8766 服务未被重启。

验证：品牌与首页、媒体范围、Dashboard 模式共 26 项测试通过；账号相关 18 项通过；主题同步 4 项通过。新增 Python 模块与测试的 Ruff 检查和格式检查通过，相关文件 diff 无空白问题。浏览器截图在 `output/playwright/homepage-video-2026-10-22/`。

现有服务立即可见视频区块，新增 Range 支持需重启 Dashboard 进程后加载。保留了工作区原有未提交改动；没有启动仿真、模型调用或远程部署。
