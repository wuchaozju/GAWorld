## API 实现与关联修复

- 新增账号绑定的个人 API 令牌：名称、世界、权限、到期、列表、撤销、最近使用。
- 生成时二次校验密码；密钥只显示一次，数据库只存摘要；改密/重置密码撤销现有令牌。
- 管理入口在账号设置页，继续使用登录会话；个人令牌不能再创建其他令牌。
- Bearer 明确失败时不回退到管理员 Cookie 或用户 Cookie。
- 个人令牌绑定本人世界，即使由管理员生成也不继承全站权限。
- 首批授权平行实验读取与运行，其他 API 默认拒绝；配置参数仍受安全白名单限制。
- 修复平行实验任务读取/停止的账号与世界边界，补齐启动/解读的软配额检查。
- 启动受互斥保护，实验目录增加随机后缀，避免并发启动或同秒同名覆盖。
- 多用户平行实验子进程固定使用发起者世界的配置，并保留个人模型凭据的原有加载机制。
- 文档：[`API_TOKEN_INTEGRATION.md`](../API_TOKEN_INTEGRATION.md)，可直接交给李兆峰。
