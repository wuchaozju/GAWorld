# 组织智能：异常恢复与交互验收

## 修复与新增

- 历史记录接口成功返回的实验 `error` 字段被误当成 HTTP 请求失败，导致中断记录无法打开；现仅按 HTTP 响应状态判断请求是否成功。
- 新增错误分类及安全诊断。原实验 Cb13e99eb2c6a4adab3428076 的日志记录为 MiniMax HTTP 429 / Token Plan 2062。相邻更早请求还有2067，分别处理速率限制与套餐用量上限，不混为同一原因。
- 运行控制区提供保留进度的重新运行、暂停、继续及终止。暂停等待当前请求结束并保存，等待请求间隔可中断。限流后保留进度并等待手动重试；相邻新请求至少10秒，无自动重试或模型切换。
- 自定义对照可输入文字、通过当前模型提取、核对与编辑规则后采用。冻结时验证人数和规则，保存/重开恢复来源及完整对照。仅比较通信结构时，预览与实际冻结的其他机制一致。
- 按钮显示处理中、暂停中、已保存、已采用及等待重试等状态，并依据前置条件禁用；历史显示正确的秒级时间、当前选中项和实时进度。保存后链接更新为当前实验。
- 评审格式错误不再永久复用无效响应；保留失败证据并允许在原2次请求上限内手动重试，耗尽时禁用重试并提示另建。
