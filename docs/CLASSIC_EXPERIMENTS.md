# 经典实验库：居民当被试

**模块**：`gaworld/experiments/classics/` · **CLI**：`python -m gaworld.experiments.classics` · **测试**：`tests/test_classic_experiments.py`

把六个教科书范式交给城里的居民来答，看扮演这些居民的模型能不能**在方向上**复现人类的经典结果。
每个范式都是两个条件的对比，方向是文献公认的；人类的数字放在旁边对照，不参与判定。

和 [需求估计实验](DEMAND_EXPERIMENT.md) 共用被试（`gaworld/experiments/subjects.py`：
同一份状态 CSV 与档案，被试就是仿真里的那个人）和续跑习惯，但不碰仿真本身。

---

## 1. 六个范式

| id | 范式 | 指标 | 预期方向 | 人类结果（对照） | 出处 |
|---|---|---|---|---|---|
| `framing` | 框架效应（罕见传染病问题） | 选确定方案的比例 | 获益框架 > 损失框架 | 72% vs 22% | Tversky & Kahneman 1981 |
| `anchoring` | 锚定效应（西湖周长 / 非洲象体重 / 2023 年出生人口，三题） | 估计值的 log10 | 高锚 > 低锚 | 锚定指数平均约 0.5 | Jacowitz & Kahneman 1995；Klein et al. 2014 |
| `dictator_ultimatum` | 独裁者 vs 最后通牒（提议方，分 100 元） | 分给对方的比例 | 最后通牒 > 独裁者 | 约 28% vs 约 40% | Forsythe et al. 1994；Engel 2011；Oosterbeek et al. 2004 |
| `ultimatum_responder` | 最后通牒（回应方） | 拒绝的比例 | 给 20 元 > 给 50 元 | 50 元几乎都接受；低于两成约一半被拒 | Güth et al. 1982；Camerer 2003 |
| `trust_ingroup` | 信任博弈（转出的钱变三倍） | 转出的比例 | 同小区居民 > 外地人 | 对陌生人约一半；群体内合作 d≈0.3 | Berg et al. 1995；Johnson & Mislin 2011；Balliet et al. 2014 |
| `public_goods_mpcr` | 一次性公共品博弈（四人一组） | 投入的比例 | 每投 1 元每人得 0.75 > 得 0.3 | 首轮约 40–60%；回报率越高投得越多 | Isaac & Walker 1988；Ledyard 1995 |

题面全部本地化（本市、罕见传染病、元），金额都是「假设这是一笔真钱」的 100 元。

## 2. 设计

- **每个居民答每个条件，各自一次无状态调用。** 两次调用互相看不见，所以不是被试内设计的那种污染；
  反过来，同一个人的两个条件可以配对——同一个人、获益框架和损失框架——这是人类实验只能靠随机分组近似的东西。
  锚定的三题在人内先算「高锚 − 低锚」再取平均。
- **提示词不提实验。** system 只说「扮演一位真实的中国城市居民，只输出 JSON」；题面里没有「实验」「框架」「锚」
  之类的字样（测试锁住）。居民的档案（姓名、年龄、职业、住处、月收入、性格、日常）放在题面前面，两个条件一字不差。
- **原始回答全部落盘**，解析在分析时做：改了解析器只需重新分析，不用重跑。

## 3. 判定

对每个范式：每人先在条件内把多次采样平均，再算「处理 − 对照」；效应 = 各人差值的平均，
95% 区间用对居民的 bootstrap，p 值用配对符号翻转检验（与平行世界的配对门槛同一套，`gaworld/parallel/causal.py`）。

| 判定 | 条件 |
|---|---|
| **复现** | 方向与经典结论一致，且 p < 0.05 |
| **反向** | 方向相反，且 p < 0.05 |
| **未复现** | 其余 |
| **样本不足** | 两个条件都有可读回答的居民少于 10 人 |

- **只读方向。** 按 `benchmark/MECHANISM_PROVENANCE.md`，这些回答是 (c) 级：说的是扮演居民的模型怎么答，
  不是现实效应多大。报告把居民的水平和人类的数字并排放，但不比大小。
- **异质性是探索性的**：按月收入、年龄的中位数分两半各算一次效应，至少 20 对才算，不进判定。
- 读不出的回答（没有 JSON、金额超出 0–100、估计值不为正）不计入，报告里写明条数。
- 结果混合了多个模型时，报告顶部标出来。

## 4. 怎么跑

```bash
python -m gaworld.experiments.classics list                      # 六个范式
python -m gaworld.experiments.classics run --dry-run             # 先看调用数，不花钱
python -m gaworld.experiments.classics run framing anchoring --subject-limit 20
python -m gaworld.experiments.classics run                       # 全部六个，默认 40 位居民
python -m gaworld.experiments.classics analyze                   # 只重新分析
```

输出在 `output/experiments/classics/<name>/`（默认 `default`）：`results.jsonl`（每次调用一行，含原始回答、
居民的年龄与月收入、路由到的 provider）、`spec.json`、`summary.json`、`report.md`。中断后重跑同一条命令即续跑，
失败的格子会重试；同名运行正在写时拒绝第二个写入者；前 20 次调用全部失败时中止（额度用完、key 失效）。

**成本**（`--draws 1`）：每个居民在每个范式里答 2 次，锚定 6 次。默认 40 位居民、全部六个范式共 **640 次调用**；
`--subject-limit` 与 `--draws` 按比例放大。被试来自当前配置的 `csv_path` / `md_path`，选了城市就是那座城的居民。

## 6. 已知限制

1. **模型可能是在背课本。** 这六个都是最有名的实验，措辞本地化挡不住识别。复现首先说明模型知道人类会怎么答，
   不等于居民「有」这种行为倾向。每个范式的 `caveat` 写了它特有的问题（例如「同一小区」也可能被读成以后还会碰面）。
2. **钱是假想的。** 人类数字来自真实激励；模型的「公平」不花任何代价。
3. **一次性、无记忆。** 被试不经过仿真的认知管线、不带记忆，只带档案与月收入；
   这一层回答的是「这些人设下的模型」，不是「在城里生活过一段时间的居民」。
4. **人类数字只做对照**：口径各异（美国大学生、实验室、元分析均值），不做拟合，也不该被拿来调提示词。
