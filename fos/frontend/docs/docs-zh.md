<h2 id="getting-started">FOS 快速入门</h2>

FOS（Future of Society）是一个在线社会仿真平台，无需下载，在浏览器中直接运行。创建 AI 驱动的智能体，在树状实验结构中互动，分析仿真结果。

### 注册 FOS 账号

1. 打开 FOS 首页，点击 **注册**。
2. 填写邮箱、用户名、组织、密码。请务必记下密码 —— FOS 暂不支持密码找回。
3. 提交后登录进入 FOS 工作台。

### 第一场 FOS 仿真

1. 在 FOS 仪表盘上，点击 **Launch Experiment**。
2. 从场景库中选择一个场景 —— FOS 提供 16 个可用场景，涵盖 5 个类别（博弈论、社会学、讨论、空间、生成城市）。
3. 按照 6 步实验构建向导完成配置（选择场景 → 配置参数 → 设置行动 → 配置智能体 → 设置网络 → 审查确认）。
4. 点击 **Launch** 创建并启动仿真。

### 观察 FOS 智能体互动

1. 仿真在 **工作区（Workspace）** 标签页中打开。左侧（左侧）显示 **SimTree** —— 实验节点的垂直树状可视化。
2. 右侧（右侧）显示 **LogViewer**，实时展示智能体对话。
3. 点击任意节点的 **推进（Advance）** 创建子节点 —— 仿真推进一轮，智能体依次响应。你可以从任意节点创建分支，探索不同的发展路径。

<h2 id="llm-config">在 FOS 中配置大模型</h2>

FOS 需要至少一个 LLM 提供商，智能体才能思考和对话。你也可以配置搜索提供商，让智能体查询外部信息。

### 打开 LLM 设置

在 FOS 导航栏进入 **设置 → LLM 提供商**，点击 **新增提供商**。

### 选择接入方式

**方式一：官方 API**（需要稳定的国际网络）

在 FOS 提供商表单中填写：
- **提供商**：OpenAI 或 Gemini
- **API 密钥**：从 [OpenAI](https://auth.openai.com/log-in) 或 [Google AI Studio](https://aistudio.google.com/api-keys) 获取
- **Base URL**：通常为 `https://api.openai.com/v1`
- **模型**：例如 `gpt-4o-mini` 或 `gemini-1.5-flash-latest`

![LLM 提供商配置](/tutorial/01-overview.png)

**方式二：API 中转站**（推荐中国大陆用户）

使用 [OpenRouter](https://openrouter.ai/) 等中转站。提供商选择 **OpenAI 兼容**，粘贴中转站提供的 API Key、Base URL 和模型名称。

![API 中转站配置](/tutorial/02-dashboard.png)

### 测试并保存

在 FOS 中点击 **测试连接**，通过后保存提供商。

### （可选）添加搜索提供商

进入 **设置 → 搜索提供商**，配置 Serper、SerpAPI 或 Tavily 的 API Key 和 Base URL。

<h2 id="creating-simulation">创建 FOS 仿真</h2>

仿真实验是让 AI 智能体在你设定的条件下互动的过程。FOS 采用树状实验模型：每次推进创建一个子节点，你可以从任意节点分支探索不同路径。

### 开始新建仿真

在 FOS 仪表盘或顶部导航栏，点击 **Launch Experiment**，或从工作台的 Desk Lab 区域进入 **New Simulation**。

![新建仿真](/tutorial/03-new-simulation.png)

### 选择场景

FOS 包含 18 个场景定义，涵盖 5 个类别，其中 16 个已完全支持：

| 类别 | 场景 |
|---|---|
| **博弈论** | 囚徒困境、性别战、猎鹿博弈、公共物品博弈、协调博弈 |
| **社会学** | 社会规范突变、政策意义磨损、回声室效应、资源稀缺、西湖医联宝招生扩散 |
| **讨论** | 开放讨论、议事会 |
| **空间** | 网格世界、传染扩散 |
| **生成城市** | GAWorld |
| **自定义** | 自定义场景（自行构建） |

前端还提供 6 个**系统模板**，内置预设智能体组：社会规范突变、政策传播中的意义磨损、极化与数字茧房生成、稀缺资源下的社会契约、乡村治理、议事会。

### 配置实验参数

1. 填写实验名称，可选设置时间配置。
2. 根据所选场景调整出现的场景专属参数。
3. 点击 **下一步** 逐步完成向导各步骤。

<h2 id="agents">配置 FOS 智能体</h2>

智能体是仿真中的人群。FOS 提供三种方式填充实验，且每种智能体类型可独立指定 LLM 提供商，实现分层模型分配。

### 手动配置

自行定义智能体类型 —— 设置标签、数量、角色提示词、用户画像、自定义属性以及可选的 LLM 提供商。每种智能体类型可指定不同的提供商，让你为不同角色分配不同模型（如领导者使用 GPT-4o，追随者使用 GPT-4o-mini）。

### 人口统计生成（AI 驱动）

1. 在实验构建器中点击 **人口统计生成**。
2. 设置人口统计类别（年龄、职业）、原型概率和属性分布（0–100 打分）。
3. 输入智能体总数，选择用于生成的提供商。
4. 点击 **生成** —— FOS 调用 LLM 创建真实的智能体画像，包括姓名、角色、头像和背景。
5. 预览生成的智能体列表并保存。

![智能体生成界面](/tutorial/04-agent-generation.png)

### 文件导入

上传包含智能体定义的 CSV 或 JSON 文件，FOS 会自动解析。

### 系统模板智能体

6 个系统模板包含针对各场景预先构建的智能体组。例如，政策传播模板创建 20 个三级结构智能体（顶层发布者、中层传播者、基层接收者）。可直接使用，也可进一步自定义。

### 创建仿真

检查智能体，做最后的微调，点击 **Launch** 创建仿真并进入仿真界面。

![仿真视图](/tutorial/05-simulation-view.png)

<h2 id="running-analysis">在 FOS 中运行与分析</h2>

这是在 FOS 仿真界面中运行实验和研究结果的阶段。

### 仿真界面布局

仿真页面通过左侧 **TabRail** 提供 4 个标签页：

- **工作区（Workspace）** —— 主视图。左侧面板（左侧）显示 **SimTree**（仿真节点树）。右侧面板（右侧）显示 **LogViewer**（智能体对话）或 **ComparisonView**（分支对比模式）。

![主机面板与智能体对话](/tutorial/06-host-panel.png)
- **智能体（Agents）** —— 侧边栏，列出所有智能体及其画像和当前状态。
- **干预（Intervention）** —— 在仿真进行中注入事件或修改条件的工具。
- **分析（Analyse）** —— 分析与指标仪表盘。

### 树状仿真模型

FOS 采用**树状结构**进行仿真，而非简单的线性序列：

- **推进（Advance）** 从当前节点创建**子节点**。每次推进执行一轮：智能体根据可见性模式被提示，处理其响应，计算收益。
- **分支（Branch）** 从任意节点创建**兄弟分支**，让你从同一起点并行探索不同方案。
- 可删除子树（根节点除外）来修剪不需要的分支。
- **自动推进（Auto-advance）** 以可配置的间隔重复推进，适合长时间的无人值守运行。

### 四种可见性模式

FOS 支持 4 种模式，控制每轮智能体看到的信息：

| 模式 | 行为 |
|---|---|
| **同步（Simultaneous）** | 所有智能体同时被提示（受 LLM 并发限制约束）。智能体无法看到其他智能体当前轮的决策。 |
| **顺序（Sequential）** | 智能体逐个被提示。每个智能体可看到本轮中已行动者的选择。 |
| **随机（Random）** | 每轮随机打乱智能体顺序后再进行顺序提示。 |
| **配对（Paired）** | 每轮随机组对；配对内的智能体相互交互。 |

![实验设计](/tutorial/07-experiment-design.png)

### 筛选日志

使用 LogViewer 中的 **筛选** 控件，按智能体、事件类型或轮次范围查看指定数据。

### 生成 AI 分析报告

点击 **分析报告** 打开报告面板。FOS 生成 AI 驱动的分析报告，支持以下可配置设置：
- **报告章节**：执行摘要、关键事件、优化建议、智能体分析、多模态缩略图
- **设置项**：最大事件数、每轮采样数、轮次范围、关注智能体、启用/禁用 LLM 优化
- **导出格式**：JSON 和 Markdown

![分析与报告](/tutorial/08-analytics.png)

### 导出数据

点击 **导出** 打开导出面板，提供两种导出范围：
- **全部日志** —— 完整仿真日志，JSON 或 CSV 格式，从后端流式传输。
- **智能体数据** —— 智能体属性与画像，JSON 或 CSV 格式，本地处理并解析 LLM 提供商信息。

![导出报告](/tutorial/10-export-reports.png)

### 保存为模板

点击 **保存为模板**，下次创建仿真时在 **我的模板** 中即可直接调用。

<h2 id="advanced-features">FOS 进阶功能</h2>

掌握基础操作后，这些工具可以帮助你深入探索仿真实验。

### 社交网络拓扑

控制智能体之间的网络连接方式 —— 不同的网络结构会改变信息传播效果。FOS 提供 8 种拓扑预设，均使用确定性种子随机数（相同种子始终生成相同网络）：

| 预设 | 描述 | 参数 |
|---|---|---|
| **全连接（Full）** | 所有智能体两两相连 | 无 |
| **随机（Random）** | Erdős–Rényi 随机图 | 连接概率 |
| **环形（Ring）** | 环形图 | 无 |
| **星形（Star）** | 所有智能体连接到中心枢纽 | 无 |
| **Newman-Watts** | 小世界网络 | 每侧邻居数、捷径概率 |
| **核心-边缘（Core-Periphery）** | 密集核心 + 稀疏边缘 | 影响力者比例、连接度 |
| **Holme-Kim** | 带聚类的无标度网络 | 每节点新连接数、聚类概率 |
| **Waxman** | 基于距离的随机图 | 最大距离、距离效应 |
| **SBM** | 随机块模型 | 组大小、组内连通性、桥接连接数 |

所有预设均保证无孤立节点。在仿真视图中打开 **网络编辑器**，选择预设、自定义参数、预览网络并保存拓扑设置。

![网络拓扑编辑器](/tutorial/09-network-topology.png)

### 全局知识库

为智能体提供共享的背景知识，可在对话中引用。知识库使用真实的语义搜索：

1. 在仿真视图或实验设置期间打开 **全局知识面板**。
2. **添加文本知识** —— 直接输入标题和内容。
3. **上传文档** —— 拖放 PDF、TXT、DOCX 或 Markdown 文件（每个最大 10MB）。
4. 文档自动分块并使用 **MiniLM**（sentence-transformers）生成嵌入向量。
5. 仿真过程中，智能体通过 **RAG**（检索增强生成）检索相关知识 —— 知识库片段基于语义相似度被注入智能体的提示上下文中。
6. 随时编辑或删除知识项 —— 无需重启仿真。

知识库支持丰富的上下文注入：每个条目记录来源类型、文件名、创建者和创建时间戳。
